# افزودن ساعت به تاریخ در Dynamics CRM (استپ Add Hours)

این استپ تعداد مشخصی ساعت به یک تاریخ و زمان اضافه می‌کند یا از آن کم می‌کند.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Add Hours** را انتخاب کنید.

## پارامترهای ورودی

* **Original Date (اجباری)** : تاریخ و زمان اولیه.
* **Hours To Add (اجباری)** : تعداد ساعت (عدد صحیح). عدد منفی به عقب برمی‌گردد.

## پارامتر خروجی

* **Updated Date** : تاریخ و زمان جدید.

## مثال

| Original Date (UTC) | Hours To Add | Updated Date |
|---|---|---|
| 2026-09-24 08:30:15 | `30` | 2026-09-25 14:30:15 |

## نکته‌ها

* اگر بیش از ۲۴ ساعت اضافه کنید، تاریخ هم جلو می‌رود (مثال بالا).
* تعداد ساعت باید عدد صحیح باشد. برای نیم ساعت از [Add Minutes](add-minutes.md) با `30` استفاده کنید.
* برای مهلت‌هایی که فقط روزهای کاری را می‌شمارند از [Add Business Days](add-business-days.md) استفاده کنید.
