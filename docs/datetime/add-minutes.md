# افزودن دقیقه به تاریخ در Dynamics CRM (استپ Add Minutes)

این استپ تعداد مشخصی دقیقه به یک تاریخ و زمان اضافه می‌کند یا از آن کم می‌کند.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Add Minutes** را انتخاب کنید.

## پارامترهای ورودی

* **Original Date (اجباری)** : تاریخ و زمان اولیه.
* **Minutes To Add (اجباری)** : تعداد دقیقه (عدد صحیح). عدد منفی به عقب برمی‌گردد.

## پارامتر خروجی

* **Updated Date** : تاریخ و زمان جدید.

## مثال

| Original Date (UTC) | Minutes To Add | Updated Date |
|---|---|---|
| 2026-09-24 08:30:15 | `-90` | 2026-09-24 07:00:15 |

## نکته‌ها

* برای اضافه کردن ساعت‌های کامل از [Add Hours](add-hours.md) استفاده کنید.
* ثانیه‌ی تاریخ اولیه حفظ می‌شود.
