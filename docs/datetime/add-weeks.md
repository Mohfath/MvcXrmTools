# افزودن هفته به تاریخ در Dynamics CRM (استپ Add Weeks)

این استپ تعداد مشخصی هفته (هر هفته ۷ روز) به یک تاریخ اضافه می‌کند یا از آن کم می‌کند. ساعت، دقیقه و ثانیه بدون تغییر می‌ماند.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Add Weeks** را انتخاب کنید.

## پارامترهای ورودی

* **Original Date (اجباری)** : تاریخ اولیه.
* **Weeks To Add (اجباری)** : تعداد هفته. عدد منفی به عقب برمی‌گردد.

## پارامتر خروجی

* **Updated Date** : تاریخ جدید.

## مثال

| Original Date (UTC) | Weeks To Add | Updated Date |
|---|---|---|
| 2026-09-24 08:30:15 | `2` | 2026-10-08 08:30:15 |

## نکته‌ها

* افزودن یک هفته دقیقاً برابر افزودن ۷ روز است ([Add Days](add-days.md)).
* برای ماه و سال از [Add Months](add-months.md) و [Add Years](add-years.md) استفاده کنید.
