# افزودن سال میلادی به تاریخ در Dynamics CRM (استپ Add Years)

این استپ تعداد مشخصی **سال میلادی** به یک تاریخ اضافه می‌کند یا از آن کم می‌کند. ساعت، دقیقه و ثانیه بدون تغییر می‌ماند.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Add Years** را انتخاب کنید.

## پارامترهای ورودی

* **Original Date (اجباری)** : تاریخ اولیه.
* **Years To Add (اجباری)** : تعداد سال. عدد منفی به عقب برمی‌گردد.

## پارامتر خروجی

* **Updated Date** : تاریخ جدید.

## مثال

| Original Date (UTC) | Years To Add | Updated Date |
|---|---|---|
| 2024-02-29 10:00 | `1` | 2025-02-28 10:00 |

## نکته‌ها

* اگر تاریخ اولیه ۲۹ فوریه‌ی سال کبیسه باشد و سال مقصد کبیسه نباشد، نتیجه ۲۸ فوریه می‌شود.
* سال **میلادی** جمع می‌شود، نه شمسی. برای سال شمسی، سال میلادی معادل را در نظر بگیرید یا از [Get Date Persian Parts](../persian/get-date-persian-parts.md) استفاده کنید.
* برای ماه از [Add Months](add-months.md) استفاده کنید.
