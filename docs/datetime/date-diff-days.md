# محاسبه‌ی اختلاف دو تاریخ بر حسب روز در Dynamics CRM (استپ Date Diff Days)

این استپ اختلاف دو تاریخ را بر حسب **روز** (عدد صحیح و همیشه نامنفی) برمی‌گرداند.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Date Diff Days** را انتخاب کنید.

## پارامترهای ورودی

* **Starting Date (اجباری)** : تاریخ اول.
* **Ending Date (اجباری)** : تاریخ دوم.

## پارامتر خروجی

* **Days Difference** : تعداد روز اختلاف (عدد صحیح، همیشه بزرگ‌تر یا مساوی صفر؛ ترتیب دو تاریخ مهم نیست).

## مثال

| اختلاف واقعی | Days Difference |
|---|---|
| ۱٫۵ روز | `2` |
| ۲٫۵ روز | `2` |
| ۳٫۵ روز | `4` |
| ۰٫۴۹ روز | `0` |
| ۲٫۹ روز | `3` |
| ۲ روز (Starting Date قبل از Ending Date) | `2` |

## نکته‌ی مهم: گرد کردن، نه بریدن

نتیجه **گرد می‌شود**، بریده نمی‌شود. یعنی اگر اختلاف ۲٫۹ روز باشد نتیجه `3` است، نه `2`. گرد کردن به روش «نزدیک‌ترین عدد زوج» است: اختلاف `1.5` روز می‌شود `2`، اختلاف `2.5` روز هم می‌شود `2`، و `3.5` می‌شود `4`. اگر می‌خواهید فقط روزهای **کامل** را بشمارید، پیش از استفاده از این استپ ساعت هر دو تاریخ را با [Set Time](set-time.md) روی یک مقدار ثابت بگذارید (مثلاً `00:00:00`) تا اختلاف همیشه عدد صحیح باشد.

## نکته‌ها

* برای روزهای کاری از [Business Days Between](business-days-between.md) استفاده کنید.
* برای اختلاف به‌صورت متن خوانا از [Date Diff](date-diff.md) استفاده کنید.
