# محاسبه‌ی اختلاف دو تاریخ بر حسب ماه میلادی در Dynamics CRM (استپ Date Diff Months)

این استپ تعداد **ماه‌های میلادیِ کامل** بین دو تاریخ را برمی‌گرداند (عدد صحیح و همیشه نامنفی).

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Date Diff Months** را انتخاب کنید.

## پارامترهای ورودی

* **Starting Date (اجباری)** : تاریخ اول.
* **Ending Date (اجباری)** : تاریخ دوم.

## پارامتر خروجی

* **Months Difference** : تعداد ماه کامل بین دو تاریخ (ترتیب دو تاریخ مهم نیست).

## مثال

| از | تا | Months Difference |
|---|---|---|
| 2026-01-15 | 2026-09-24 | `8` |
| 2026-01-10 | 2026-02-10 | `1` |
| 2026-01-31 | 2026-02-28 | `0` |
| 2026-01-31 | 2026-03-01 | `1` |
| 2026-09-24 | 2026-01-15 (برعکس) | `8` |

## نکته‌ها

* فقط ماه‌های **کامل** شمرده می‌شوند: از ۳۱ ژانویه تا ۲۸ فوریه یک ماه کامل نگذشته است (`0`)، ولی تا ۱ مارس گذشته است (`1`).
* ماه **میلادی** است، نه شمسی. ساعت و دقیقه در محاسبه دخیل نیستند.
* برای سال کامل از [Date Diff Years](date-diff-years.md) و برای روز از [Date Diff Days](date-diff-days.md) استفاده کنید.
