# محاسبه‌ی اختلاف دو تاریخ بر حسب ثانیه در Dynamics CRM (استپ Date Diff Seconds)

این استپ اختلاف دو تاریخ را بر حسب **ثانیه** (عدد صحیح و همیشه نامنفی) برمی‌گرداند. میلی‌ثانیه‌ی هر دو تاریخ نادیده گرفته می‌شود.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Date Diff Seconds** را انتخاب کنید.

## پارامترهای ورودی

* **Starting Date (اجباری)** : تاریخ اول.
* **Ending Date (اجباری)** : تاریخ دوم.

## پارامتر خروجی

* **Seconds Difference** : تعداد ثانیه‌ی اختلاف (عدد صحیح، همیشه بزرگ‌تر یا مساوی صفر؛ ترتیب دو تاریخ مهم نیست).

## مثال

| Starting Date | Ending Date | Seconds Difference |
|---|---|---|
| 09:01:05 | 09:00:00 (همان روز) | `65` |

## نکته‌ها

* خروجی عدد صحیح است؛ اگر اختلاف بسیار بزرگ باشد (بیش از حدود ۶۸ سال) از حد عدد صحیح ۳۲ بیتی فراتر می‌رود. برای اختلاف‌های طولانی از [Date Diff Days](date-diff-days.md) یا [Date Diff Minutes](date-diff-minutes.md) استفاده کنید.
* برای اختلاف به‌صورت متن از [Date Diff](date-diff.md) استفاده کنید.
