# اختلاف دو تاریخ به‌صورت متن خوانا در Dynamics CRM (استپ Date Diff)

این استپ اختلاف دو تاریخ را به‌صورت یک متن خوانا برمی‌گرداند؛ شامل روز، ساعت و دقیقه (و در صورت نیاز ثانیه)، مثلاً `2d.03h:20m`.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Date Diff** را انتخاب کنید.

## پارامترهای ورودی

* **Starting Date (اجباری)** : تاریخ اول.
* **Ending Date (اجباری)** : تاریخ دوم.
* **Show Seconds (اجباری، پیش‌فرض: False)** : اگر `True` باشد، ثانیه هم در متن نوشته می‌شود.

## پارامتر خروجی

* **Difference** : اختلاف به شکل `Xd.HHh:MMm` یا با ثانیه `Xd.HHh:MMm:SSs` (`X` تعداد روز است).

## مثال

با Starting Date برابر 2026-09-24 08:30:15 و Ending Date برابر 2026-09-22 05:10:00:

| Show Seconds | Difference |
|---|---|
| `False` | `2d.03h:20m` |
| `True` | `2d.03h:20m:15s` |

## نکته‌ها

* اختلاف به‌صورت **Starting Date منهای Ending Date** حساب می‌شود. اگر Starting Date قبل از Ending Date باشد، همه‌ی بخش‌ها منفی نوشته می‌شوند؛ مثلاً `-2d.-03h:-20m:-15s`. اگر نتیجه‌ی مثبت می‌خواهید، تاریخ بزرگ‌تر را در Starting Date بگذارید.
* اگر دو تاریخ برابر باشند، نتیجه `0d.00h:00m:00s` است.
* ساعت و دقیقه دورقمی هستند (`03h`، `20m`) ولی روز بدون صفر ابتدایی است.
* برای گرفتن اختلاف به‌صورت **عدد** از [Date Diff Days](date-diff-days.md)، [Date Diff Hours](date-diff-hours.md)، [Date Diff Minutes](date-diff-minutes.md) و مشابه استفاده کنید.
