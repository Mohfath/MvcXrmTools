# گرفتن شماره‌ی روز هفته از تاریخ در Dynamics CRM (استپ Get Day Number Of Week)

این استپ شماره‌ی روز هفته را برمی‌گرداند. شماره‌گذاری از **یکشنبه** شروع می‌شود: یکشنبه `1`، دوشنبه `2` … شنبه `7`.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Get Day Number Of Week** را انتخاب کنید.

## پارامترهای ورودی

* **Date To Use (اجباری)** : تاریخ موردنظر.
* **Evaluate As User Local (اجباری، پیش‌فرض: True)** : اگر `True` باشد، تاریخ پیش از محاسبه با منطقه‌ی زمانی کاربر اجراکننده‌ی Workflow به وقت محلی تبدیل می‌شود؛ اگر `False`، همان UTC استفاده می‌شود.

## پارامتر خروجی

* **Day Number Of Week** : شماره‌ی روز هفته از `1` تا `7`.

## جدول شماره‌ها

| روز | Day Number Of Week | نمونه‌ی تاریخ |
|---|---|---|
| یکشنبه (Sunday) | `1` | 2026-09-20 |
| دوشنبه (Monday) | `2` | 2026-09-21 |
| سه‌شنبه (Tuesday) | `3` | |
| چهارشنبه (Wednesday) | `4` | |
| پنج‌شنبه (Thursday) | `5` | 2026-09-24 |
| جمعه (Friday) | `6` | 2026-09-25 |
| شنبه (Saturday) | `7` | 2026-09-26 |

## نکته‌ها

* **شماره‌گذاری از یکشنبه است، نه از شنبه.** هفته‌ی ایرانی از شنبه شروع می‌شود؛ پس شنبه در این استپ `7` است. اگر شماره‌ی روز هفته‌ی ایرانی می‌خواهید (شنبه `1`)، عدد را با استپ‌های [Add](../numeric/add.md) و شرط‌ها تبدیل کنید یا از [Get Day Of Week](get-day-of-week.md) نام روز را بگیرید.
* برای نام فارسی روز از [Format Persian DateTime](../persian/format-persian-date-time.md) با `dddd` استفاده کنید.
