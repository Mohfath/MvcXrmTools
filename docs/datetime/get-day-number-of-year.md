# گرفتن شماره‌ی روز در سال از تاریخ در Dynamics CRM (استپ Get Day Number Of Year)

این استپ شماره‌ی روز در **سال میلادی** را برمی‌گرداند: ۱ ژانویه `1` و ۳۱ دسامبر `365` (یا `366` در سال کبیسه).

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Get Day Number Of Year** را انتخاب کنید.

## پارامترهای ورودی

* **Date To Use (اجباری)** : تاریخ موردنظر.
* **Evaluate As User Local (اجباری، پیش‌فرض: True)** : اگر `True` باشد، تاریخ پیش از محاسبه با منطقه‌ی زمانی کاربر اجراکننده‌ی Workflow به وقت محلی تبدیل می‌شود؛ اگر `False`، همان UTC استفاده می‌شود.

## پارامتر خروجی

* **Day Number Of Year** : شماره‌ی روز در سال.

## مثال

| Date To Use | Day Number Of Year |
|---|---|
| 2026-09-24 | `267` |

## نکته‌ها

* سال **میلادی** است؛ روز اول آن ۱ ژانویه است، نه اول فروردین.
* برای شمارش روزهای سال شمسی از [Get Date Persian Parts](../persian/get-date-persian-parts.md) (ماه و روز) استفاده کنید.
