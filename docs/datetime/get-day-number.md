# گرفتن روز ماه از تاریخ در Dynamics CRM (استپ Get Day Number)

این استپ شماره‌ی **روز ماه میلادی** یک تاریخ را برمی‌گرداند (`1` تا `31`).

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Get Day Number** را انتخاب کنید.

## پارامترهای ورودی

* **Date To Use (اجباری)** : تاریخ موردنظر.
* **Evaluate As User Local (اجباری، پیش‌فرض: True)** : اگر `True` باشد، تاریخ ورودی (که در CRM به‌صورت UTC است) پیش از محاسبه با **منطقه‌ی زمانی کاربر اجراکننده‌ی Workflow** به وقت محلی تبدیل می‌شود. اگر `False` باشد، همان UTC استفاده می‌شود.

## پارامتر خروجی

* **Day Number** : روز ماه میلادی.

## مثال

با منطقه‌ی زمانی کاربر برابر UTC+3:30 (ایران):

| Date To Use (UTC) | Evaluate As User Local | Day Number |
|---|---|---|
| 2026-09-22 21:00 | `False` | `22` |
| 2026-09-22 21:00 | `True` | `23` (چون ساعت ۰۰:۳۰ روز بعد به وقت کاربر است) |

## نکته‌ها

* منطقه‌ی زمانی از تنظیمات شخصی همان کاربر در CRM خوانده می‌شود. برای کاربر ایرانی آن را روی «تهران (UTC+03:30)» بگذارید.
* این استپ روز **میلادی** را می‌دهد. برای روز ماه شمسی از [Get Date Persian Parts](../persian/get-date-persian-parts.md) استفاده کنید.
