# تبدیل تاریخ به متن با قالب دلخواه در Dynamics CRM (استپ Get Formatted Date String)

این استپ یک تاریخ را با **قالب دلخواه** به متن تبدیل می‌کند؛ مثلاً `09/24/2026 08:30` یا `2026-09-24`. قالب همان الگوهای سفارشی تاریخ در .NET است.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Get Formatted Date String** را انتخاب کنید.

## پارامترهای ورودی

* **Date To Use (اجباری)** : تاریخ موردنظر.
* **Evaluate As User Local (اجباری، پیش‌فرض: True)** : اگر `True` باشد، تاریخ پیش از قالب‌دهی با منطقه‌ی زمانی کاربر اجراکننده‌ی Workflow به وقت محلی تبدیل می‌شود؛ اگر `False`، همان UTC استفاده می‌شود.
* **Format (اجباری، پیش‌فرض: `MM/dd/yyyy HH:mm`)** : الگوی قالب.

## پارامتر خروجی

* **Formatted Date** : تاریخ قالب‌بندی‌شده.

## مثال

برای 2026-09-24 08:30:15 (UTC) با `Evaluate As User Local = False` و زبان انگلیسی (آمریکا) روی سرور:

| Format | Formatted Date |
|---|---|
| `MM/dd/yyyy HH:mm` | `09/24/2026 08:30` |
| `yyyy-MM-dd` | `2026-09-24` |
| `dddd, dd MMMM yyyy` | `Thursday, 24 September 2026` |
| `yyyy-MM-dd'T'HH:mm:ss` | `2026-09-24T08:30:15` |
| `HH:mm` | `08:30` |
| `d MMM yyyy` | `24 Sep 2026` |

با `Evaluate As User Local = True` و کاربری با منطقه‌ی زمانی UTC+3:30، قالب `HH:mm` می‌شود `12:00`.

## نکته‌ی مهم: به زبان (Culture) سرور بستگی دارد

نام ماه‌ها و روزها و **نوع تقویم** از تنظیمات زبان Windows سرور CRM گرفته می‌شود. اگر Culture سرور روی فارسی (`fa-IR`) باشد، همین استپ **تاریخ شمسی** می‌دهد: قالب `yyyy/MM/dd` می‌شود `1405/07/02` و `dddd d MMMM` می‌شود «پنجشنبه 2 مهر». روی سرور انگلیسی همان قالب‌ها تاریخ میلادی می‌دهند. پس نتیجه‌ی این استپ روی دو سرور مختلف ممکن است فرق کند.

اگر می‌خواهید **همیشه تاریخ شمسی** بگیرید (مستقل از تنظیمات سرور) و ارقام فارسی هم داشته باشید، از [Format Persian DateTime](../persian/format-persian-date-time.md) استفاده کنید.

## نکته‌ها

* قالب باید معتبر باشد؛ الگوهای پرکاربرد: `yyyy` سال، `MM` ماه دورقمی، `dd` روز، `HH` ساعت ۲۴ ساعته، `mm` دقیقه، `ss` ثانیه. متن ثابت را بین `'` بگذارید.
* برای تبدیل به متن با Culture دلخواه به‌جای Culture سرور از [To UTC String](to-utc-string.md) استفاده کنید.
