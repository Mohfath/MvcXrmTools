# گرفتن نام ماه از تاریخ در Dynamics CRM (استپ Get Month Name)

این استپ نام ماه یک تاریخ را برمی‌گرداند و **زبان (Culture)** را خودتان انتخاب می‌کنید. اگر Culture را `fa-IR` بگذارید، نام **ماه شمسی** (مثلاً «مهر») برگردانده می‌شود.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Get Month Name** را انتخاب کنید.

## پارامترهای ورودی

* **Date To Use (اجباری)** : تاریخ موردنظر.
* **Evaluate As User Local (اجباری، پیش‌فرض: True)** : اگر `True` باشد، تاریخ پیش از محاسبه با منطقه‌ی زمانی کاربر اجراکننده‌ی Workflow به وقت محلی تبدیل می‌شود؛ اگر `False`، همان UTC استفاده می‌شود.
* **Culture (اختیاری، پیش‌فرض: `en-US`)** : کد زبان، مثل `en-US`، `fa-IR`، `fr-FR`، `de-DE`.

## پارامتر خروجی

* **Month Name** : نام ماه به زبان و تقویمِ Culture انتخاب‌شده.

## مثال

برای تاریخ 2026-09-24:

| Culture | Month Name | توضیح |
|---|---|---|
| `en-US` | September | |
| `fa-IR` | **مهر** | ماه **شمسی** (۲ مهر ۱۴۰۵) |
| `de-DE` | September | |
| `fr-FR` | septembre | |
| `tr-TR` | Eylül | |
| `ar-SA` | ربيع الثاني | ماه **قمری (هجری)** عربستان |

## نکته‌ها

* **برای نام ماه شمسی** `fa-IR` را بنویسید؛ کتابخانه‌ی .NET برای فرهنگ فارسی از تقویم شمسی استفاده می‌کند.
* اگر Culture را خالی بگذارید یا نامی ناشناخته بدهید (مثلاً `xx-invalid`)، استپ خطا نمی‌دهد و نام انگلیسی ماه را برمی‌گرداند.
* برای نام ماه شمسی همراه با روز و سال یا قالب دلخواه، [Format Persian DateTime](../persian/format-persian-date-time.md) (با الگوی `MMMM`) قابل‌اعتمادتر است چون به فرهنگ‌های نصب‌شده روی سرور وابسته نیست.
* برای شماره‌ی ماه میلادی از [Get Month Number](get-month-number.md) استفاده کنید.
