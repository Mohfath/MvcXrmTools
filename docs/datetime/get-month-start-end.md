# گرفتن اولین و آخرین لحظه‌ی ماه در Dynamics CRM (استپ Get Month Start End)

این استپ اولین و آخرین لحظه‌ی **ماه میلادی** یک تاریخ را برمی‌گرداند. برای گرفتن همه‌ی رکوردهای یک ماه یا ساختن بازه‌ی گزارش مفید است.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Get Month Start End** را انتخاب کنید.

## پارامترهای ورودی

* **Date To Use (اجباری)** : تاریخ موردنظر.
* **Evaluate As User Local (اجباری، پیش‌فرض: True)** : اگر `True` باشد، تاریخ پیش از محاسبه با منطقه‌ی زمانی کاربر اجراکننده‌ی Workflow به وقت محلی تبدیل می‌شود؛ اگر `False`، همان UTC استفاده می‌شود.

## پارامترهای خروجی

* **Month Start Date** : اولین لحظه‌ی ماه، روز ۱ ساعت `00:00:00`.
* **Month End Date** : آخرین لحظه‌ی ماه، آخرین روز ماه ساعت `23:59:59.999`.

## مثال

| Date To Use | Month Start Date | Month End Date |
|---|---|---|
| 2026-09-24 | 2026-09-01 00:00:00 | 2026-09-30 23:59:59.999 |
| 2028-02-10 (سال کبیسه) | 2028-02-01 00:00:00 | 2028-02-29 23:59:59.999 |

## نکته‌ی مهم: خروجی به وقت محلی است

مقدارهای برگشتی تاریخ و ساعتی هستند که **بدون تبدیل دوباره به UTC** داده می‌شوند. اگر `Evaluate As User Local = True` باشد، خروجی به **وقت محلی کاربر** است؛ مثلاً برای ورودی 2026-09-30 21:00 UTC و کاربر UTC+3:30 (که در ایران هنوز اول اکتبر است) نتیجه‌ی شروع ماه `2026-10-01 00:00:00` می‌شود. اگر این تاریخ‌ها را در جستجو یا فیلد CRM (که UTC انتظار دارد) به کار می‌برید، اختلاف منطقه‌ی زمانی را در نظر بگیرید یا `Evaluate As User Local = False` بگذارید تا همه‌چیز UTC بماند.

## نکته‌ها

* ماه **میلادی** است. برای ماه شمسی، ابتدا با [Get Date Persian Parts](../persian/get-date-persian-parts.md) روز ماه شمسی را بگیرید و با [Add Days](add-days.md) به اول ماه شمسی برگردید.
* مشابه: [Get Quarter Start End](get-quarter-start-end.md)، [Get Week Start End](get-week-start-end.md) و [Get Year Start End](get-year-start-end.md).
