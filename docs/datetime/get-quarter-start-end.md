# گرفتن اولین و آخرین لحظه‌ی فصل در Dynamics CRM (استپ Get Quarter Start End)

این استپ اولین و آخرین لحظه‌ی **فصل (سه‌ماهه‌ی) میلادی** یک تاریخ را برمی‌گرداند.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Get Quarter Start End** را انتخاب کنید.

## پارامترهای ورودی

* **Date To Use (اجباری)** : تاریخ موردنظر.
* **Evaluate As User Local (اجباری، پیش‌فرض: True)** : اگر `True` باشد، تاریخ پیش از محاسبه با منطقه‌ی زمانی کاربر اجراکننده‌ی Workflow به وقت محلی تبدیل می‌شود؛ اگر `False`، همان UTC استفاده می‌شود.

## پارامترهای خروجی

* **Quarter Start Date** : اولین لحظه‌ی فصل، روز ۱ ماهِ اول فصل ساعت `00:00:00`.
* **Quarter End Date** : آخرین لحظه‌ی فصل، آخرین روز ماهِ سوم فصل ساعت `23:59:59.999`.

## مثال

| Date To Use | Quarter Start Date | Quarter End Date |
|---|---|---|
| 2026-09-24 | 2026-07-01 00:00:00 | 2026-09-30 23:59:59.999 |

## نکته‌ها

* فصل‌ها **میلادی** هستند: ژانویه تا مارس، آوریل تا ژوئن، ژوئیه تا سپتامبر، اکتبر تا دسامبر. با فصل‌های شمسی (بهار از اول فروردین) یکی نیستند.
* خروجی‌ها بدون تبدیل دوباره به UTC و در همان وقتی که محاسبه شده (محلی یا UTC، بسته به Evaluate As User Local) داده می‌شوند؛ توضیح در [Get Month Start End](get-month-start-end.md).
* برای شماره‌ی فصل از [Get Quarter Number Of Year](get-quarter-number-of-year.md) استفاده کنید.
