# گرفتن شماره‌ی هفته‌ی سال از تاریخ در Dynamics CRM (استپ Get Week Number Of Year)

این استپ شماره‌ی هفته‌ی یک تاریخ را در سال میلادی برمی‌گرداند.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Get Week Number Of Year** را انتخاب کنید.

## پارامترهای ورودی

* **Date To Use (اجباری)** : تاریخ موردنظر.
* **Evaluate As User Local (اجباری، پیش‌فرض: True)** : اگر `True` باشد، تاریخ پیش از محاسبه با منطقه‌ی زمانی کاربر اجراکننده‌ی Workflow به وقت محلی تبدیل می‌شود؛ اگر `False`، همان UTC استفاده می‌شود.

## پارامتر خروجی

* **Week Number Of Year** : شماره‌ی هفته.

## مثال

با تنظیمات زبان انگلیسی (آمریکا) روی سرور (هفته از یکشنبه شروع می‌شود و هفته‌ی اول شامل ۱ ژانویه است):

| Date To Use | Week Number Of Year |
|---|---|
| 2026-01-01 | `1` |
| 2026-01-03 | `1` |
| 2026-01-04 | `2` |
| 2026-09-24 | `39` |
| 2026-12-31 | `53` |

## نکته‌ی مهم: به تنظیمات زبان سرور بستگی دارد

قاعده‌ی شماره‌گذاری هفته (کدام روز اول هفته است و کدام هفته «هفته‌ی اول» حساب می‌شود) از تنظیمات زبان و منطقه‌ی **Windows سرور CRM** (Culture) گرفته می‌شود. روی سرورهای با تنظیمات دیگر ممکن است شماره‌ی هفته برای یک تاریخ فرق کند (مثلاً در بعضی تنظیمات، هفته از دوشنبه شروع می‌شود). قبل از استفاده در گزارش‌ها روی چند تاریخ مرزی (اول و آخر سال) نتیجه را بررسی کنید.

## نکته‌ها

* این هفته‌ی **سال میلادی** است و با هفته‌ی سال شمسی (که از شنبه شروع می‌شود) یکی نیست.
* برای اولین و آخرین روز هفته از [Get Week Start End](get-week-start-end.md) استفاده کنید.
