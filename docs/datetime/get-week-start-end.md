# گرفتن اولین و آخرین لحظه‌ی هفته در Dynamics CRM (استپ Get Week Start End)

این استپ اولین و آخرین لحظه‌ی هفته‌ی یک تاریخ را برمی‌گرداند. **هفته از یکشنبه شروع و به شنبه ختم می‌شود.**

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Get Week Start End** را انتخاب کنید.

## پارامترهای ورودی

* **Date To Use (اجباری)** : تاریخ موردنظر.
* **Evaluate As User Local (اجباری، پیش‌فرض: True)** : اگر `True` باشد، تاریخ پیش از محاسبه با منطقه‌ی زمانی کاربر اجراکننده‌ی Workflow به وقت محلی تبدیل می‌شود؛ اگر `False`، همان UTC استفاده می‌شود.

## پارامترهای خروجی

* **Week Start Date** : اولین لحظه‌ی هفته، **یکشنبه** ساعت `00:00:00`.
* **Week End Date** : آخرین لحظه‌ی هفته، **شنبه** ساعت `23:59:59.999`.

## مثال

| Date To Use | Week Start Date | Week End Date |
|---|---|---|
| 2026-09-24 (پنج‌شنبه) | 2026-09-20 00:00:00 (یکشنبه) | 2026-09-26 23:59:59.999 (شنبه) |
| 2026-09-20 (یکشنبه) | 2026-09-20 00:00:00 | 2026-09-26 23:59:59.999 |
| 2026-09-26 (شنبه) | 2026-09-20 00:00:00 | 2026-09-26 23:59:59.999 |

## نکته‌ها

* **هفته‌ی ایرانی از شنبه شروع می‌شود، ولی این استپ هفته را از یکشنبه می‌شمارد.** اگر هفته‌ی ایرانی (شنبه تا جمعه) لازم دارید، از [Add Days](add-days.md) و [Get Day Number Of Week](get-day-number-of-week.md) کمک بگیرید: روز شنبه با شماره‌ی `7` مشخص می‌شود.
* خروجی‌ها بدون تبدیل دوباره به UTC داده می‌شوند؛ توضیح در [Get Month Start End](get-month-start-end.md).
