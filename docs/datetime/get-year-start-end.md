# گرفتن اولین و آخرین لحظه‌ی سال در Dynamics CRM (استپ Get Year Start End)

این استپ اولین و آخرین لحظه‌ی **سال میلادی** یک تاریخ را برمی‌گرداند.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Get Year Start End** را انتخاب کنید.

## پارامترهای ورودی

* **Date To Use (اجباری)** : تاریخ موردنظر.
* **Evaluate As User Local (اجباری، پیش‌فرض: True)** : اگر `True` باشد، تاریخ پیش از محاسبه با منطقه‌ی زمانی کاربر اجراکننده‌ی Workflow به وقت محلی تبدیل می‌شود؛ اگر `False`، همان UTC استفاده می‌شود.

## پارامترهای خروجی

* **Year Start Date** : اولین لحظه‌ی سال، ۱ ژانویه ساعت `00:00:00`.
* **Year End Date** : آخرین لحظه‌ی سال، ۳۱ دسامبر ساعت `23:59:59.999`.

## مثال

| Date To Use | Year Start Date | Year End Date |
|---|---|---|
| 2026-09-24 | 2026-01-01 00:00:00 | 2026-12-31 23:59:59.999 |

## نکته‌ها

* سال **میلادی** است؛ شروع آن ۱ ژانویه است، نه اول فروردین.
* خروجی‌ها بدون تبدیل دوباره به UTC داده می‌شوند؛ توضیح در [Get Month Start End](get-month-start-end.md).
