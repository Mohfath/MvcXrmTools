# بررسی قرار داشتن تاریخ بین دو تاریخ در Dynamics CRM (استپ Is Between)

این استپ بررسی می‌کند که یک تاریخ **دقیقاً بین** دو تاریخ دیگر قرار دارد یا نه.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Is Between** را انتخاب کنید.

## پارامترهای ورودی

* **Starting Date (اجباری)** : ابتدای بازه.
* **Date To Validate (اجباری)** : تاریخی که بررسی می‌شود.
* **Ending Date (اجباری)** : انتهای بازه.

## پارامتر خروجی

* **Between** : اگر تاریخ **بعد از ابتدا و قبل از انتها** باشد `True` و در غیر این صورت `False` است.

## مثال

با بازه‌ی 2026-09-01 تا 2026-09-30:

| Date To Validate | Between |
|---|---|
| 2026-09-15 | `True` |
| 2026-09-01 (برابر ابتدا) | `False` |
| 2026-09-30 (برابر انتها) | `False` |
| 2026-10-01 | `False` |

## نکته‌ها

* **دو سر بازه شامل نمی‌شوند.** اگر تاریخ دقیقاً با ابتدا یا انتها برابر باشد، نتیجه `False` است. برای شامل بودن سرها، بازه را کمی بزرگ‌تر کنید (مثلاً یک ثانیه پیش از ابتدا و بعد از انتها با [Add Minutes](add-minutes.md)).
* اگر Starting Date بعد از Ending Date باشد، نتیجه همیشه `False` است (جابه‌جا نمی‌شوند).
* مقایسه با تاریخ و ساعت انجام می‌شود، نه فقط روز.
