# بررسی یکی بودن روز دو تاریخ در Dynamics CRM (استپ Is Same Day)

این استپ بررسی می‌کند که دو تاریخ در یک روز تقویمی (میلادی) هستند یا نه، صرف‌نظر از ساعت.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Is Same Day** را انتخاب کنید.

## پارامترهای ورودی

* **First Date (اجباری)** : تاریخ اول.
* **Second Date (اجباری)** : تاریخ دوم.
* **Evaluate As User Local (اجباری، پیش‌فرض: True)** : اگر `True` باشد، هر دو تاریخ پیش از مقایسه با منطقه‌ی زمانی کاربر اجراکننده‌ی Workflow به وقت محلی تبدیل می‌شوند؛ اگر `False`، همان UTC مقایسه می‌شود.

## پارامتر خروجی

* **Same Day** : اگر هر دو تاریخ در یک روز باشند `True` و در غیر این صورت `False` است.

## مثال

با منطقه‌ی زمانی کاربر برابر UTC+3:30 (ایران):

| First Date (UTC) | Second Date (UTC) | Evaluate As User Local | Same Day |
|---|---|---|---|
| 2026-09-22 20:00 | 2026-09-22 21:00 | `False` | `True` |
| 2026-09-22 20:00 | 2026-09-22 21:00 | `True` | `False` (۲۳:۳۰ و ۰۰:۳۰ روز بعد) |
| 2026-09-22 10:00 | 2026-09-23 10:00 | `False` | `False` |

## نکته‌ها

* برای کاربر ایرانی همیشه `Evaluate As User Local = True` بگذارید تا «روز» با ساعت دیواری ایران حساب شود؛ وگرنه زمان‌های بعد از ساعت ۲۰:۳۰ UTC (نیمه‌شب ایران) در روز قبل حساب می‌شوند.
* روز، روز **میلادی** است؛ نیمه‌شب همان نیمه‌شب معمولی است.
