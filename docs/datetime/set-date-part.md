# تغییر یک بخش از تاریخ در Dynamics CRM (استپ Set Date Part)

این استپ فقط **یک بخش** از یک تاریخ (ساعت، دقیقه، ثانیه، ماه، روز یا سال میلادی) را با مقدار جدید عوض می‌کند و بقیه‌ی بخش‌ها را نگه می‌دارد.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Set Date Part** را انتخاب کنید.

## پارامترهای ورودی

* **Date To Update (اجباری)** : تاریخ اولیه.
* **Date Part HR/MIN/SEC MON/DAY/YR (اجباری)** : بخشی که عوض می‌شود. یکی از مقدارهای زیر (بزرگی و کوچکی حروف مهم نیست):

| مقدار | بخش | مقدار مجاز `New Value` |
|---|---|---|
| `HR` | ساعت | `0` تا `23` |
| `MIN` | دقیقه | `0` تا `59` |
| `SEC` | ثانیه | `0` تا `59` |
| `MON` | ماه (میلادی) | `1` تا `12` |
| `DAY` | روز ماه | `1` تا `31` (باید در همان ماه وجود داشته باشد) |
| `YR` | سال (میلادی) | `1900` تا `9999` |

* **New Value (اجباری)** : مقدار جدید بخش.

## پارامتر خروجی

* **Updated Date** : تاریخ جدید.

## مثال

با Date To Update برابر 2026-09-24 08:30:15:

| Date Part | New Value | Updated Date |
|---|---|---|
| `HR` | `15` | 2026-09-24 15:30:15 |
| `MIN` | `5` | 2026-09-24 08:05:15 |
| `SEC` | `59` | 2026-09-24 08:30:59 |
| `MON` | `2` | 2026-02-24 08:30:15 |
| `DAY` | `15` | 2026-09-15 08:30:15 |
| `YR` | `2030` | 2030-09-24 08:30:15 |

## خطاها

| شرایط | پیام |
|---|---|
| Date Part یکی از مقدارهای بالا نیست (مثلاً `HOUR`) | `Invalid date part - must be HR/MIN/SEC MON/DAY/YR` |
| ساعت بیرون از `0` تا `23` | `Invalid hour` |
| دقیقه یا ثانیه بیرون از `0` تا `59` | `Invalid minute` / `Invalid second` |
| ماه بیرون از `1` تا `12` | `Invalid month` |
| روز بیشتر از ۳۱ | `Invalid day` |
| سال بیرون از `1900` تا `9999` | `Invalid year` |
| تاریخ ساخته‌شده وجود ندارد (مثلاً روز `31` برای شهریور، `DAY` = `0`، یا `MON` = `2` روی ۳۱ ژانویه) | `Update resulted in invalid date` |

## نکته‌ها

* تغییر ماه یا روز مقداری را تنظیم می‌کند که ممکن است در آن ماه وجود نداشته باشد؛ در این حالت به‌جای تنظیم خودکار، خطا می‌دهد (مثلاً تغییر ماهِ ۳۱ ژانویه به فوریه).
* برای تنظیم ساعت، دقیقه و ثانیه با هم از [Set Time](set-time.md) استفاده کنید.
* بخش‌ها **میلادی** هستند؛ سال و ماه شمسی را نمی‌توان با این استپ مستقیم تغییر داد.
