# تنظیم ساعت، دقیقه و ثانیه‌ی تاریخ در Dynamics CRM (استپ Set Time)

این استپ ساعت، دقیقه و ثانیه‌ی یک تاریخ را با مقدارهای دلخواه جایگزین می‌کند و **روز را نگه می‌دارد**. مثلاً برای اینکه یک تاریخ همیشه ساعت ۰۰:۰۰:۰۰ (اول روز) باشد.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Set Time** را انتخاب کنید.

## پارامترهای ورودی

* **Date To Update (اجباری)** : تاریخ اولیه (روز از آن گرفته می‌شود).
* **Hour (24-hour) (اجباری، پیش‌فرض: `12`)** : ساعت، `0` تا `23`.
* **Minute (اجباری، پیش‌فرض: `0`)** : دقیقه، `0` تا `59`.
* **Second (اجباری، پیش‌فرض: `0`)** : ثانیه، `0` تا `59`.

## پارامتر خروجی

* **Updated Date** : تاریخ با ساعت جدید.

## مثال

با Date To Update برابر 2026-09-24 08:30:15:

| Hour | Minute | Second | Updated Date |
|---|---|---|---|
| `15` | `45` | `30` | 2026-09-24 15:45:30 |
| `0` | `0` | `0` | 2026-09-24 00:00:00 |

## خطاها

| شرایط | پیام |
|---|---|
| ساعت بیرون از `0` تا `23` (مثلاً `24`) | `Invalid hour` |
| دقیقه بیرون از `0` تا `59` | `Invalid minute` |
| ثانیه بیرون از `0` تا `59` | `Invalid second` |

## نکته‌ها

* پیش‌فرض ساعت `12` است (ظهر)، نه نیمه‌شب؛ اگر می‌خواهید اول روز باشد، ساعت را `0` بگذارید.
* میلی‌ثانیه‌ی تاریخ اولیه صفر می‌شود.
* برای تغییر فقط یک بخش از [Set Date Part](set-date-part.md) استفاده کنید.
* کاربرد رایج: پیش از [Date Diff Days](date-diff-days.md) ساعت دو تاریخ را یکی کنید تا اختلاف روز دقیق باشد.
