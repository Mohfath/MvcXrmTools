# تبدیل متن به تاریخ در Dynamics CRM (استپ To Date Time)

این استپ یک متن را به تاریخ و زمان تبدیل می‌کند و مشخص می‌کند تبدیل موفق بود یا نه.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **To Date Time** را انتخاب کنید.

## پارامترهای ورودی

* **Text To Convert (اجباری)** : متنی که باید به تاریخ تبدیل شود.

## پارامترهای خروجی

* **Converted Date** : تاریخ و زمان تبدیل‌شده. اگر تبدیل ناموفق باشد، مقدار پیش‌فرض یعنی `0001-01-01 00:00:00` است.
* **Is Valid Date** : اگر تبدیل موفق باشد `True` و در غیر این صورت `False` است.

## مثال

با تنظیمات زبان انگلیسی (آمریکا) روی سرور:

| Text To Convert | Is Valid Date | Converted Date |
|---|---|---|
| `2026-09-24` | `True` | 2026-09-24 00:00:00 |
| `2026-09-24 15:30` | `True` | 2026-09-24 15:30:00 |
| `9/24/2026 3:30 PM` | `True` | 2026-09-24 15:30:00 |
| `September 24, 2026` | `True` | 2026-09-24 00:00:00 |
| `12:30` | `True` | **امروز** ساعت 12:30 |
| `24/09/2026` | `False` | 0001-01-01 |
| `2026-13-45` | `False` | 0001-01-01 |
| `abc` | `False` | 0001-01-01 |
| خالی | `False` | 0001-01-01 |

## نکته‌ها

* متن نامعتبر خطا نمی‌دهد؛ فقط **Is Valid Date** برابر `False` می‌شود. پیش از استفاده از **Converted Date** این خروجی را با یک شرط (Check Condition) بررسی کنید.
* خواندن متن بر اساس **تنظیمات زبان سرور** انجام می‌شود؛ مثلاً `24/09/2026` روی سرور انگلیسی (آمریکا) معتبر نیست ولی روی سرورهای با ترتیب روز/ماه معتبر است. برای متن‌های ثابت از قالب بی‌ابهام `2026-09-24` استفاده کنید.
* متنی که فقط ساعت دارد، امروز را به‌عنوان تاریخ می‌گیرد.
* **این استپ برای تبدیل متن تاریخ شمسی طراحی نشده است.** نتیجه‌ی تبدیل متنی مثل `1405/07/02` به تنظیمات زبان سرور بستگی دارد و قابل اتکا نیست؛ برای تاریخ شمسی نباید روی این استپ حساب کنید.
* برای تبدیل تاریخ به متن از [Get Formatted Date String](get-formatted-date-string.md) یا [Format Persian DateTime](../persian/format-persian-date-time.md) استفاده کنید.
