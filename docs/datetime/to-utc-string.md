# تبدیل تاریخ به متن UTC در Dynamics CRM (استپ To UTC String)

این استپ یک تاریخ را به **زمان UTC** تبدیل و آن را با قالب استاندارد زبان (Culture) انتخاب‌شده به متن تبدیل می‌کند.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **To UTC String** را انتخاب کنید.

## پارامترهای ورودی

* **Date To Format (اجباری)** : تاریخ موردنظر.
* **Culture (اختیاری، پیش‌فرض: `en-US`)** : کد زبان، مثل `en-US`، `fa-IR`، `de-DE`، `fr-FR`، `ja-JP`. اگر خالی باشد، زبان سرور استفاده می‌شود.

## پارامتر خروجی

* **Formatted Date String** : تاریخ و زمانِ UTC به‌صورت متن، با قالب پیش‌فرض همان Culture.

## مثال

برای 2026-09-24 08:30:15 (UTC):

| Culture | Formatted Date String |
|---|---|
| `en-US` | `9/24/2026 8:30:15 AM` |
| `fa-IR` | `02/07/1405 08:30:15 ق.ظ` |
| `de-DE` | `24.09.2026 08:30:15` |
| `fr-FR` | `24/09/2026 08:30:15` |
| `ja-JP` | `2026/09/24 8:30:15` |
| خالی | مثل زبان سرور (مثال: `9/24/2026 8:30:15 AM`) |

## نکته‌ها

* قالب خروجی ثابت است و قابل تنظیم نیست؛ فقط زبان را تعیین می‌کنید. برای قالب دلخواه از [Get Formatted Date String](get-formatted-date-string.md) و برای تاریخ شمسی با قالب دلخواه از [Format Persian DateTime](../persian/format-persian-date-time.md) استفاده کنید.
* برای `fa-IR` تاریخ به‌صورت **شمسی** با ترتیب `روز/ماه/سال` نوشته می‌شود (مثال بالا: `02/07/1405`).
* اگر Culture ناشناخته باشد (مثلاً `xx-invalid`)، استپ با خطای `Culture is not supported.` متوقف می‌شود.
* تاریخی که CRM می‌دهد UTC است و بدون تغییر نوشته می‌شود. تاریخی که نوع آن مشخص نیست (Unspecified) به‌عنوان وقت محلی سرور فرض و به UTC تبدیل می‌شود.
