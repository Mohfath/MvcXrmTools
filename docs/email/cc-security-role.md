# افزودن کاربران یک نقش امنیتی به رونوشت (CC) ایمیل در Dynamics CRM (استپ Cc Security Role)

این استپ همه‌ی کاربرانی را که یک نقش امنیتی (Security Role) دارند به خط **CC** (رونوشت) یک ایمیل اضافه می‌کند. کار آن مثل [Email Security Role](email-security-role.md) است، با این تفاوت که خط CC را پر می‌کند.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Cc Security Role** را انتخاب کنید. ایمیل باید از قبل ساخته شده باشد.

## پارامترهای ورودی

* **Email To Send (اجباری)** : ایمیلی که گیرنده‌ها به آن اضافه می‌شوند (Lookup به ایمیل).
* **Security Role GUID (اجباری)** : شناسه‌ی یکتا (GUID) نقش امنیتی، به‌صورت **متن** (Lookup نیست).
* **Send Email? (اجباری، پیش‌فرض: False)** : اگر `True` باشد، بعد از اضافه شدن گیرنده‌ها ایمیل فرستاده می‌شود.

## پارامتر خروجی

* **Users Added** : تعداد **کل** گیرنده‌های خط CC پس از اجرای استپ، شامل گیرنده‌هایی که از قبل روی خط CC بودند.

## نحوه‌ی کار

* فقط کاربرانی اضافه می‌شوند که نقش به‌طور مستقیم به آن‌ها داده شده، **فعال** هستند و **آدرس ایمیل داخلی** دارند. کاربری که از قبل روی خط CC باشد دوباره اضافه نمی‌شود.
* اگر GUID معتبر نباشد، استپ با خطای `Invalid Role GUID` متوقف می‌شود.

## نکته‌ها

* اگر روی خط CC گیرنده‌ای باشد که فقط یک آدرس ایمیل تایپ‌شده است (و به رکورد کاربر یا مخاطب وصل نیست)، استپ با خطا متوقف می‌شود.
* استپ با دسترسی کاربر اجراکننده‌ی Workflow اجرا می‌شود.
