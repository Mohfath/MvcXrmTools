# ساخت موضوع و متن ایمیل از روی قالب در Dynamics CRM (استپ Create Template)

این استپ یک قالب ایمیل (Email Template) را برای یک رکورد مشخص پر می‌کند و **موضوع** و **متن** حاصل را برمی‌گرداند. خودِ استپ ایمیلی نمی‌سازد و نمی‌فرستد؛ فقط نتیجه‌ی قالب را در اختیار شما می‌گذارد تا در استپ‌های بعدی (مثلاً ساخت ایمیل) استفاده کنید.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Create Template** را انتخاب کنید.

## پارامترهای ورودی

* **Template (اجباری)** : قالب ایمیل (Lookup به Email Template).
* **Record Dynamic Url (اجباری)** : آدرس داینامیک رکوردی که قالب برای آن پر می‌شود. برای پر کردن آن از مقدار **Record URL (Dynamic)** رکورد موردنظر در Dynamic Values استفاده کنید.

## پارامترهای خروجی

* **Template Subject** : موضوع ایمیل پس از پر شدن قالب. اگر قالب موضوع نداشته باشد، خالی است.
* **Template Description** : متن (بدنه‌ی) ایمیل پس از پر شدن قالب. معمولاً HTML است. اگر قالب متن نداشته باشد، خالی است.

## نکته‌ها

* نوع قالب باید با نوع رکورد آدرس یکی باشد (مثلاً قالبِ مخصوص Account برای رکورد Account). در غیر این صورت استپ با خطای `Template type does not match entity in record url` متوقف می‌شود.
* استپ با دسترسی کاربر اجراکننده‌ی Workflow اجرا می‌شود.
