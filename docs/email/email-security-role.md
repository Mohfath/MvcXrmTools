# افزودن کاربران یک نقش امنیتی به گیرنده‌های ایمیل در Dynamics CRM (استپ Email Security Role)

این استپ همه‌ی کاربرانی را که یک نقش امنیتی (Security Role) دارند به خط **To** (گیرنده) یک ایمیل اضافه می‌کند و در صورت نیاز ایمیل را می‌فرستد.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Email Security Role** را انتخاب کنید. ایمیل باید از قبل ساخته شده باشد.

## پارامترهای ورودی

* **Email To Send (اجباری)** : ایمیلی که گیرنده‌ها به آن اضافه می‌شوند (Lookup به ایمیل).
* **Security Role GUID (اجباری)** : شناسه‌ی یکتا (GUID) نقش امنیتی، به‌صورت **متن**. این پارامتر Lookup نیست؛ GUID نقش را باید وارد کنید.
* **Send Email? (اجباری، پیش‌فرض: False)** : اگر `True` باشد، بعد از اضافه شدن گیرنده‌ها ایمیل فرستاده می‌شود.

## پارامتر خروجی

* **Users Added** : تعداد **کل** گیرنده‌های خط To پس از اجرای استپ، شامل گیرنده‌هایی که از قبل روی ایمیل بودند.

## نحوه‌ی کار

* گیرنده‌های قبلی حفظ می‌شوند و کاربران نقش بعد از آن‌ها اضافه می‌شوند.
* فقط کاربرانی اضافه می‌شوند که نقش به‌طور مستقیم به آن‌ها داده شده، **فعال** هستند و **آدرس ایمیل داخلی** دارند. اگر کاربری از قبل گیرنده باشد، دوباره اضافه نمی‌شود.
* اگر متنی که در Security Role GUID وارد کرده‌اید GUID معتبر نباشد، استپ با خطای `Invalid Role GUID` متوقف می‌شود.

## نکته‌ها

* GUID نقش را می‌توانید از آدرس صفحه‌ی نقش در CRM بردارید.
* اگر روی خط To گیرنده‌ای باشد که فقط یک آدرس ایمیل تایپ‌شده است (و به رکورد کاربر یا مخاطب وصل نیست)، استپ با خطا متوقف می‌شود.
* استپ با دسترسی کاربر اجراکننده‌ی Workflow اجرا می‌شود.
* برای خط **CC** از [Cc Security Role](cc-security-role.md) استفاده کنید.
