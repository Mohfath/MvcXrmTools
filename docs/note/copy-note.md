# کپی یادداشت (Note) زیر رکورد دیگر در Dynamics CRM (استپ Copy Note)

این استپ یک یادداشت (Note) را زیر رکورد دیگری کپی می‌کند. یادداشت اصلی سر جای خودش می‌ماند و یک یادداشت جدید با همان متن و عنوان (و در صورت انتخاب، همان فایل پیوست) زیر رکورد مقصد ساخته می‌شود.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Copy Note** را انتخاب کنید.

## پارامترهای ورودی

* **Note To Copy (اجباری)** : یادداشتی که باید کپی شود (Lookup به یادداشت).
* **Record Dynamic Url (اجباری)** : آدرس داینامیک رکوردی که یادداشت کپی‌شده زیر آن ساخته می‌شود. برای پر کردن آن از مقدار **Record URL (Dynamic)** رکورد موردنظر در Dynamic Values استفاده کنید.
* **Copy Attachment? (اجباری، پیش‌فرض: True)** : اگر `True` باشد، فایل پیوست یادداشت (نام، حجم، نوع فایل (MIME type) و محتوای فایل) هم کپی می‌شود. اگر `False` باشد، فقط متن و عنوان کپی می‌شود و یادداشت جدید فایلی ندارد.

## پارامتر خروجی

* **Was Note Copied** : اگر یادداشت جدید ساخته شود `True` و در غیر این صورت `False` است.

## نحوه‌ی کار

* یادداشت جدید همان **متن** (Note Text) و **عنوان** (Title) یادداشت اصلی را دارد و به رکورد مقصد مربوط می‌شود (Regarding).
* اگر رکورد مقصد همان رکوردی باشد که یادداشت همین حالا به آن مربوط است، هیچ کپی‌ای ساخته نمی‌شود و **Was Note Copied** برابر `False` می‌شود. استپ خطا نمی‌دهد.
* یادداشت اصلی حذف یا تغییر نمی‌کند. اگر می‌خواهید یادداشت جابه‌جا شود، از [Move Note](move-note.md) استفاده کنید.

## نکته‌ها

* استپ با دسترسی کاربر اجراکننده‌ی Workflow اجرا می‌شود؛ پس آن کاربر باید اجازه‌ی خواندن یادداشت اصلی و ساختن یادداشت روی رکورد مقصد را داشته باشد.

## مثال کاربرد

وقتی یک Lead به Opportunity تبدیل می‌شود، آخرین یادداشت Lead را با [Get Latest Note](get-latest-note.md) پیدا کنید و با Copy Note زیر Opportunity کپی کنید.
