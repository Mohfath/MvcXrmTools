# Delete Attachment By Name (حذف پیوست بر اساس نام فایل)

این استپ فایل پیوست یک یادداشت (Note) را در صورتی که نام فایل آن با نام داده‌شده یکی باشد حذف می‌کند. **خود یادداشت (متن و عنوان) حذف نمی‌شود**؛ فقط فایل پیوست از آن برداشته می‌شود.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Delete Attachment By Name** را انتخاب کنید.

> **هشدار:** حذف فایل پیوست برگشت‌پذیر نیست.

## پارامترهای ورودی

* **Note With Attachment To Remove (اجباری)** : یادداشتی که پیوست آن ممکن است حذف شود (Lookup به یادداشت).
* **File Name With Extension (اجباری)** : نام کامل فایل همراه با پسوند، مثلاً `Report.pdf`.
* **Add Delete Notice As Text? (اجباری، پیش‌فرض: False)** : اگر `True` باشد، پس از حذف فایل، یک خط به انتهای متن یادداشت اضافه می‌شود: `Deleted Attachment: <نام فایل> <تاریخ>`.

## پارامتر خروجی

* **Number Of Attachments Deleted** : تعداد پیوست‌های حذف‌شده. چون هر یادداشت حداکثر یک فایل دارد، این عدد `0` یا `1` است.

## نحوه‌ی کار

* نام فایل باید **کامل** با نام داده‌شده یکی باشد (با پسوند). `Report` برای فایلی به نام `Report.pdf` هم‌خوانی ندارد.
* در مقایسه‌ی نام، بزرگی و کوچکی حروف مهم نیست: `REPORT.PDF` با `Report.pdf` یکی حساب می‌شود.
* اگر نام هم‌خوانی نداشته باشد یا یادداشت پیوست نداشته باشد، هیچ اتفاقی نمی‌افتد و خروجی `0` است.
* با حذف فایل، فیلدهای نام فایل، حجم و محتوای یادداشت خالی می‌شوند.

## نکته‌ها

* استپ با دسترسی کاربر اجراکننده‌ی Workflow اجرا می‌شود؛ پس آن کاربر باید اجازه‌ی تغییر یادداشت را داشته باشد.
* برای حذف بر اساس حجم یا پسوند از [Delete Attachment](delete-attachment.md) و برای حذف کل یادداشت از [Delete Note](delete-note.md) استفاده کنید.

## مثال کاربرد

با [Get Latest Note By Filename](get-latest-note-by-filename.md) یادداشتی را که فایل `draft.docx` دارد پیدا کنید و بعد با Delete Attachment By Name همان فایل را از آن بردارید.
