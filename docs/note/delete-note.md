# حذف یادداشت (Note) در Dynamics CRM (استپ Delete Note)

این استپ یک یادداشت (Note) را به‌طور کامل حذف می‌کند: متن، عنوان و فایل پیوست آن.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Delete Note** را انتخاب کنید.

> **هشدار:** حذف یادداشت برگشت‌پذیر نیست. اگر فقط می‌خواهید فایل پیوست برداشته شود و یادداشت بماند، از [Delete Attachment](delete-attachment.md) یا [Delete Attachment By Name](delete-attachment-by-name.md) استفاده کنید.

## پارامترهای ورودی

* **Note To Delete (اجباری)** : یادداشتی که باید حذف شود (Lookup به یادداشت).

## پارامتر خروجی

* **Was Note Deleted** : بعد از حذف موفق برابر `True` است. اگر حذف با خطا روبه‌رو شود (مثلاً کاربر دسترسی حذف نداشته باشد)، استپ با خطا متوقف می‌شود و Workflow ادامه پیدا نمی‌کند.

## نکته‌ها

* استپ با دسترسی کاربر اجراکننده‌ی Workflow اجرا می‌شود؛ پس آن کاربر باید اجازه‌ی حذف (Delete) آن یادداشت را داشته باشد.

## مثال کاربرد

بعد از کپی یادداشت زیر رکورد دیگر با [Copy Note](copy-note.md)، اگر می‌خواهید یادداشت اصلی حذف شود، از Delete Note استفاده کنید. (برای جابه‌جا کردن یادداشت بدون ساختن کپی، [Move Note](move-note.md) ساده‌تر است.)
