# پیدا کردن یادداشت بر اساس نام فایل پیوست در Dynamics CRM (استپ Get Latest Note By Filename)

این استپ در یادداشت‌های (Note) یک رکورد، یادداشتی را پیدا می‌کند که فایل پیوست آن نام مشخصی دارد. اگر چند یادداشت با این نام فایل وجود داشته باشد، جدیدترین آن (بر اساس تاریخ ساخت، Created On) برگردانده می‌شود.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Get Latest Note By Filename** را انتخاب کنید.

## پارامترهای ورودی

* **Filename (اجباری)** : نام فایل پیوست همراه با پسوند، مثلاً `Report.pdf`. نام باید کامل و دقیق باشد.
* **Record Dynamic Url (اجباری)** : آدرس داینامیک رکوردی که یادداشت‌های آن جستجو می‌شود. برای پر کردن آن از مقدار **Record URL (Dynamic)** رکورد موردنظر در Dynamic Values استفاده کنید.

## پارامتر خروجی

* **Found Note** : Lookup به یادداشت پیدا‌شده. اگر یادداشتی با این نام فایل روی رکورد وجود نداشته باشد، خالی است.

## نکته‌ها

* استپ فقط جستجو می‌کند و چیزی را تغییر نمی‌دهد. از **Found Note** می‌توانید به‌عنوان ورودی استپ‌های دیگر Note استفاده کنید، مثل [Delete Attachment By Name](delete-attachment-by-name.md)، [Copy Note](copy-note.md) یا [Move Note](move-note.md).
* چون ممکن است یادداشتی پیدا نشود، پیش از استفاده از **Found Note** با یک شرط (Check Condition) مطمئن شوید مقدار دارد.
* استپ با دسترسی کاربر اجراکننده‌ی Workflow اجرا می‌شود؛ پس فقط یادداشت‌هایی را پیدا می‌کند که آن کاربر اجازه‌ی خواندنشان را دارد.

## مثال کاربرد

روی یک سفارش، جدیدترین یادداشتی را که فایل `Contract.pdf` دارد پیدا کنید و آن را با [Copy Note](copy-note.md) زیر رکورد مشتری کپی کنید.
