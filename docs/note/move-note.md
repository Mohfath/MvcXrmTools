# Move Note (جابه‌جا کردن یادداشت)

این استپ یک یادداشت (Note) را از رکوردی که به آن مربوط است (Regarding) به رکورد دیگری منتقل می‌کند. برخلاف [Copy Note](copy-note.md)، یادداشت جدیدی ساخته نمی‌شود: همان یادداشت (با متن، عنوان و فایل پیوست) به رکورد مقصد وصل می‌شود.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Move Note** را انتخاب کنید.

## پارامترهای ورودی

* **Note To Move (اجباری)** : یادداشتی که باید جابه‌جا شود (Lookup به یادداشت).
* **Record Dynamic Url (اجباری)** : آدرس داینامیک رکورد مقصد. برای پر کردن آن از مقدار **Record URL (Dynamic)** رکورد موردنظر در Dynamic Values استفاده کنید.

## پارامتر خروجی

* **Was Note Moved** : اگر یادداشت به رکورد جدید منتقل شود `True` و در غیر این صورت `False` است.

## نحوه‌ی کار

* فقط رکورد مرتبط (Regarding) یادداشت عوض می‌شود؛ بقیه‌ی فیلدهای یادداشت دست نمی‌خورند.
* اگر یادداشت همین حالا به رکورد مقصد مربوط باشد، هیچ تغییری داده نمی‌شود و **Was Note Moved** برابر `False` می‌شود. استپ خطا نمی‌دهد.

## نکته‌ها

* استپ با دسترسی کاربر اجراکننده‌ی Workflow اجرا می‌شود؛ پس آن کاربر باید اجازه‌ی تغییر یادداشت را داشته باشد.
* اگر می‌خواهید یادداشت در رکورد اصلی هم بماند، از [Copy Note](copy-note.md) استفاده کنید.

## مثال کاربرد

وقتی یک Case به Case دیگری ادغام می‌شود، آخرین یادداشت آن را با [Get Latest Note](get-latest-note.md) پیدا کنید و با Move Note به Case جدید منتقل کنید.
