# تغییر متن یادداشت (Note) در Dynamics CRM (استپ Update Note Text)

این استپ متن یک یادداشت (Note) را با متن جدید **جایگزین** می‌کند.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Update Note Text** را انتخاب کنید.

## پارامترهای ورودی

* **Note To Update (اجباری)** : یادداشتی که متن آن تغییر می‌کند (Lookup به یادداشت).
* **New Text (اجباری)** : متن جدید یادداشت.

## پارامتر خروجی

* **Updated Text** : همان متنی که روی یادداشت ذخیره شد.

## نکته‌ها

* متن جدید جای متن قبلی را می‌گیرد و به آن **اضافه نمی‌شود**. اگر می‌خواهید متن قبلی بماند، آن را همراه متن جدید در New Text وارد کنید.
* فقط متن یادداشت تغییر می‌کند. عنوان و فایل پیوست دست نمی‌خورند. برای تغییر عنوان از [Update Note Title](update-note-title.md) استفاده کنید.
* استپ با دسترسی کاربر اجراکننده‌ی Workflow اجرا می‌شود؛ پس آن کاربر باید اجازه‌ی تغییر یادداشت را داشته باشد.

## مثال کاربرد

بعد از پیدا کردن آخرین یادداشت یک رکورد با [Get Latest Note](get-latest-note.md)، متن آن را با یک پیام استاندارد، مثلاً «بررسی شد»، جایگزین کنید.
