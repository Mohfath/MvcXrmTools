# Update Note Title (تغییر عنوان یادداشت)

این استپ عنوان (Title) یک یادداشت (Note) را با عنوان جدید **جایگزین** می‌کند.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Update Note Title** را انتخاب کنید.

## پارامترهای ورودی

* **Note To Update (اجباری)** : یادداشتی که عنوان آن تغییر می‌کند (Lookup به یادداشت).
* **New Title (اجباری)** : عنوان جدید یادداشت.

## پارامتر خروجی

* **Updated Title** : همان عنوانی که روی یادداشت ذخیره شد.

## نکته‌ها

* فقط عنوان یادداشت تغییر می‌کند. متن و فایل پیوست دست نمی‌خورند. برای تغییر متن از [Update Note Text](update-note-text.md) استفاده کنید.
* استپ با دسترسی کاربر اجراکننده‌ی Workflow اجرا می‌شود؛ پس آن کاربر باید اجازه‌ی تغییر یادداشت را داشته باشد.

## مثال کاربرد

بعد از کپی یادداشت با [Copy Note](copy-note.md)، عنوان یادداشت جدید را با Update Note Title عوض کنید تا مشخص باشد از کجا کپی شده است.
