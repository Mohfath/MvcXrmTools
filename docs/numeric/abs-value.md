# محاسبه‌ی قدر مطلق عدد در Dynamics CRM (استپ Abs Value)

این استپ قدر مطلق یک عدد را برمی‌گرداند؛ یعنی عدد را بدون علامت منفی.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Abs Value** را انتخاب کنید.

## پارامترهای ورودی

* **Number (اجباری)** : عددی که قدر مطلق آن خواسته شده (عدد اعشاری).

## پارامتر خروجی

* **Absolute Value** : قدر مطلق عدد.

## مثال

| Number | Absolute Value |
|---|---|
| `-5.5` | `5.5` |
| `7` | `7` |

---

منبع: این استپ از مجموعه‌ی متن‌باز LAT.WorkflowUtilities (بخش Numeric) به این پروژه آورده شده است.
