# بررسی عددی بودن متن در Dynamics CRM (استپ Is String Numeric)

این استپ بررسی می‌کند که یک متن قابل تبدیل به عدد هست یا نه.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Is String Numeric** را انتخاب کنید.

## پارامترهای ورودی

* **Number (اجباری)** : متنی که باید بررسی شود.

## پارامتر خروجی

* **Is String Numeric** : اگر متن به عدد تبدیل شود `True` و در غیر این صورت `False` است.

## مثال

| Number (متن) | Is String Numeric |
|---|---|
| `123` | `True` |
| `12.5` | `True` |
| `1,234` | `True` |
| `-7` | `True` |
| ` 42 ` (با فاصله دو طرف) | `True` |
| `1e3` | `True` |
| `abc` | `False` |
| `12a` | `False` |
| خالی | `False` |
| `۱۲۳` (رقم‌های فارسی) | `False` |
| `١٢٣` (رقم‌های عربی) | `False` |

## نکته‌ها

* **رقم‌های فارسی و عربی عدد شناخته نمی‌شوند.** اگر متن ورودی رقم فارسی دارد، پیش از این استپ رقم‌ها را به رقم انگلیسی تبدیل کنید.
* جداکننده‌ی اعشار و هزارگان طبق تنظیمات زبان (Culture) سرور CRM خوانده می‌شود. مثال‌های بالا برای زبان انگلیسی (آمریکا) هستند.
* اگر می‌خواهید خودِ عدد را هم بگیرید از [To Decimal](to-decimal.md) یا [To Integer](to-integer.md) استفاده کنید.

---

منبع: این استپ از مجموعه‌ی متن‌باز LAT.WorkflowUtilities (بخش Numeric) به این پروژه آورده شده است.
