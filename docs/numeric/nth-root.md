# محاسبه‌ی ریشه‌ی n‌ام عدد در Dynamics CRM (استپ Nth Root)

این استپ ریشه‌ی n‌ام یک عدد را حساب می‌کند؛ مثلاً ریشه‌ی دوم (جذر) یا ریشه‌ی سوم.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Nth Root** را انتخاب کنید.

## پارامترهای ورودی

* **Number (اجباری، پیش‌فرض: `1`)** : عددی که ریشه‌ی آن خواسته شده (عدد اعشاری).
* **Root Number (اجباری، پیش‌فرض: `2`)** : مرتبه‌ی ریشه؛ `2` یعنی جذر، `3` یعنی ریشه‌ی سوم.
* **Round Decimal Places (اجباری، پیش‌فرض: `-1`)** : تعداد رقم اعشاری که نتیجه به آن گرد می‌شود. مقدار `-1` یعنی گرد نکن.

## پارامتر خروجی

* **Result** : ریشه‌ی n‌ام عدد (عدد اعشاری).

## مثال

| Number | Root Number | Round Decimal Places | Result |
|---|---|---|---|
| `16` | `2` | `-1` | `4` |
| `27` | `3` | `-1` | `3` |
| `2` | `2` | `4` | `1.4142` |

## نکته‌ها

* اگر نتیجه یک عدد حقیقی نباشد، استپ با خطای `Number under the radical must be positive.` متوقف می‌شود. مثلاً ریشه‌ی سوم عدد منفی `-8` همین خطا را می‌دهد، حتی اگر از نظر ریاضی جواب داشته باشد.
* برای گرد کردن از پارامتر **Round Decimal Places** استفاده کنید؛ روش گرد کردن در [Round](round.md) توضیح داده شده است.
* عکس این عمل، توان رساندن، در [Raise To The Power](raise-to-the-power.md) است.
