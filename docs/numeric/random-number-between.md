# ساخت عدد تصادفی بین دو عدد در Dynamics CRM (استپ Random Number Between)

این استپ یک عدد صحیح تصادفی بین حد پایین و حد بالا می‌سازد.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Random Number Between** را انتخاب کنید.

## پارامترهای ورودی

* **Min Value (اجباری)** : حد پایین (خودِ این عدد جزو نتیجه‌های ممکن است). اگر کمتر از `1` باشد، مثل `0` حساب می‌شود.
* **Max Value (اجباری)** : حد بالا (خودِ این عدد **جزو نتیجه‌های ممکن نیست**). اگر کمتر از `1` باشد، مثل `1` حساب می‌شود.

## پارامتر خروجی

* **Generated Number** : عدد تصادفی ساخته‌شده.

## مثال

| Min Value | Max Value | نتیجه‌های ممکن |
|---|---|---|
| `5` | `10` | یکی از `5` تا `9` |
| `10` | `10` | همیشه `10` |
| `-3` | `5` | یکی از `0` تا `4` (حد پایین منفی مثل `0` است) |
| `10` | `5` | خطا |

## نکته‌ها

* اگر Max Value از Min Value کوچک‌تر باشد، استپ با خطای `Max Value must be greater than Min Value.` متوقف می‌شود.
* اگر Min Value و Max Value برابر باشند، همان عدد برمی‌گردد.
* این عدد برای مصارف امنیتی (رمز، توکن) مناسب نیست. دو اجرای تقریباً هم‌زمان ممکن است عدد یکسان بدهند؛ توضیح در [Random Number](random-number.md).

---

منبع: این استپ از مجموعه‌ی متن‌باز LAT.WorkflowUtilities (بخش Numeric) به این پروژه آورده شده است.
