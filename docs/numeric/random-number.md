# ساخت عدد تصادفی در Dynamics CRM (استپ Random Number)

این استپ یک عدد صحیح تصادفی از `0` تا کمتر از مقدار داده‌شده می‌سازد.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Random Number** را انتخاب کنید.

## پارامترهای ورودی

* **Max Value (اجباری)** : حد بالای عدد تصادفی. خودِ این عدد **جزو نتیجه‌های ممکن نیست** (حد بالا شامل نمی‌شود). اگر کمتر از `1` باشد، مثل `1` حساب می‌شود.

## پارامتر خروجی

* **Generated Number** : عدد تصادفی ساخته‌شده.

## مثال

| Max Value | نتیجه‌های ممکن |
|---|---|
| `10` | یکی از `0` تا `9` |
| `1` | همیشه `0` |
| `0` یا کمتر | همیشه `0` (مثل `1` حساب می‌شود) |

## نکته‌ها

* برای اینکه عدد بین `1` تا `10` بخواهید، از [Random Number Between](random-number-between.md) استفاده کنید یا `1` به نتیجه اضافه کنید.
* این عدد برای مصارف امنیتی (رمز، توکن) مناسب نیست.
* هر بار اجرای استپ، مولد اعداد تصادفی از روی زمان مقداردهی می‌شود. پس دو اجرای **تقریباً هم‌زمان** ممکن است عدد یکسان بدهند.
