# گرد کردن عدد در Dynamics CRM (استپ Round)

این استپ یک عدد را تا تعداد رقم اعشار مشخص گرد می‌کند.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Round** را انتخاب کنید.

## پارامترهای ورودی

* **Number To Round (اجباری)** : عددی که باید گرد شود (عدد اعشاری).
* **Decimal Places (اجباری)** : تعداد رقم اعشار نتیجه. مقدار منفی مانند `0` رفتار می‌کند (گرد به عدد صحیح).

## پارامتر خروجی

* **Rounded Number** : عدد گردشده.

## روش گرد کردن

گرد کردن به روش «نزدیک‌ترین عدد زوج» (Banker's Rounding) انجام می‌شود، نه «گرد کردن به بالا» که در مدرسه یاد می‌گیریم: اگر رقم حذف‌شده **دقیقاً وسط** باشد (مثل `.5`)، عدد به سمتی گرد می‌شود که رقم آخرش زوج باشد. در بقیه‌ی حالت‌ها مثل گرد کردن معمولی است.

| Number To Round | Decimal Places | Rounded Number |
|---|---|---|
| `2.5` | `0` | `2` |
| `3.5` | `0` | `4` |
| `-2.5` | `0` | `-2` |
| `1.005` | `2` | `1.00` |
| `1.006` | `2` | `1.01` |
| `3.14159` | `3` | `3.142` |
| `3.7` | `-2` | `4` |

## نکته‌ها

* این استپ گرد کردن معمولی (`2.5` ← `3`) را انجام نمی‌دهد. اگر برای نتیجه‌ی محاسبه‌ها این تفاوت مهم است (مثلاً مبلغ مالی)، آن را در نظر بگیرید.
* استپ‌های [Add](add.md)، [Subtract](subtract.md)، [Multiply](multiply.md)، [Divide](divide.md) و [Average](average.md) هم با پارامتر **Round Decimal Places** به همین روش گرد می‌کنند.
* برای بریدن اعشار بدون گرد کردن از [Truncate](truncate.md) استفاده کنید.
