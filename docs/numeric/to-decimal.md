# تبدیل متن به عدد اعشاری در Dynamics CRM (استپ To Decimal)

این استپ یک متن را به عدد اعشاری (Decimal) تبدیل می‌کند و مشخص می‌کند تبدیل موفق بود یا نه.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **To Decimal** را انتخاب کنید.

## پارامترهای ورودی

* **Text To Convert (اجباری)** : متنی که باید تبدیل شود.

## پارامترهای خروجی

* **Converted Number** : عدد اعشاری. اگر تبدیل ناموفق باشد `0` است.
* **Is Valid Decimal** : اگر تبدیل موفق باشد `True` و در غیر این صورت `False` است.

## مثال

| Text To Convert | Is Valid Decimal | Converted Number |
|---|---|---|
| `12.75` | `True` | `12.75` |
| `1,234.5` | `True` | `1234.5` |
| ` 3.5 ` | `True` | `3.5` |
| `abc` | `False` | `0` |
| خالی | `False` | `0` |
| `۱۲` (رقم فارسی) | `False` | `0` |

## نکته‌ها

* متن نامعتبر خطا نمی‌دهد؛ فقط **Is Valid Decimal** برابر `False` می‌شود. پیش از استفاده از **Converted Number** با یک شرط (Check Condition) این خروجی را بررسی کنید، وگرنه ممکن است `0` را عدد واقعی بگیرید.
* رقم‌های فارسی و عربی تبدیل نمی‌شوند؛ پیش از این استپ آن‌ها را به رقم انگلیسی تبدیل کنید.
* جداکننده‌ی اعشار و هزارگان طبق تنظیمات زبان (Culture) سرور CRM خوانده می‌شود. مثال‌های بالا برای زبان انگلیسی (آمریکا) هستند.
* برای عدد صحیح از [To Integer](to-integer.md) استفاده کنید.

---

منبع: این استپ از مجموعه‌ی متن‌باز LAT.WorkflowUtilities (بخش Numeric) به این پروژه آورده شده است.
