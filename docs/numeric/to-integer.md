# تبدیل متن به عدد صحیح در Dynamics CRM (استپ To Integer)

این استپ یک متن را به عدد صحیح (Integer) تبدیل می‌کند و مشخص می‌کند تبدیل موفق بود یا نه.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **To Integer** را انتخاب کنید.

## پارامترهای ورودی

* **Text To Convert (اجباری)** : متنی که باید تبدیل شود.

## پارامترهای خروجی

* **Converted Number** : عدد صحیح. اگر تبدیل ناموفق باشد `0` است.
* **Is Valid Integer** : اگر تبدیل موفق باشد `True` و در غیر این صورت `False` است.

## مثال

| Text To Convert | Is Valid Integer | Converted Number |
|---|---|---|
| `42` | `True` | `42` |
| `-7` | `True` | `-7` |
| ` 5 ` | `True` | `5` |
| `12.0` | `False` | `0` |
| `1,234` | `False` | `0` |
| `2147483648` | `False` | `0` |
| `abc` | `False` | `0` |

## نکته‌ها

* فقط متنی که یک عدد صحیح ساده باشد (با علامت منفی اختیاری) پذیرفته می‌شود. عدد اعشاری (`12.0`)، عدد با جداکننده‌ی هزارگان (`1,234`) و عددی که از حد عدد صحیح ۳۲ بیتی (`2,147,483,647`) بیشتر باشد معتبر نیست.
* متن نامعتبر خطا نمی‌دهد؛ فقط **Is Valid Integer** برابر `False` می‌شود. پیش از استفاده از **Converted Number** این خروجی را با یک شرط (Check Condition) بررسی کنید.
* رقم‌های فارسی و عربی تبدیل نمی‌شوند.
* برای عدد اعشاری از [To Decimal](to-decimal.md) استفاده کنید.

---

منبع: این استپ از مجموعه‌ی متن‌باز LAT.WorkflowUtilities (بخش Numeric) به این پروژه آورده شده است.
