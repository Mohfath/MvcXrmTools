# بریدن اعشار عدد بدون گرد کردن در Dynamics CRM (استپ Truncate)

این استپ اعشار یک عدد را از تعداد رقم مشخصی به بعد **می‌برد**، بدون اینکه گرد کند.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Truncate** را انتخاب کنید.

## پارامترهای ورودی

* **Number To Truncate (اجباری)** : عددی که اعشار آن بریده می‌شود (عدد اعشاری).
* **Decimal Places (اجباری)** : تعداد رقم اعشاری که نگه داشته می‌شود. مقدار منفی مانند `0` رفتار می‌کند (فقط قسمت صحیح می‌ماند).

## پارامتر خروجی

* **Truncated Number** : عدد بریده‌شده.

## مثال

| Number To Truncate | Decimal Places | Truncated Number |
|---|---|---|
| `3.789` | `2` | `3.78` |
| `-3.789` | `1` | `-3.7` |
| `5.9` | `0` | `5` |

## نکته‌ها

* رقم‌ها فقط بریده می‌شوند و گرد نمی‌شوند: `3.789` با ۲ رقم اعشار می‌شود `3.78`، نه `3.79`. اگر گرد کردن لازم دارید از [Round](round.md) استفاده کنید.
* عدد منفی به سمت صفر بریده می‌شود (`-3.789` ← `-3.7`).
