# بررسی نقش امنیتی تیم‌های کاربر در Dynamics CRM (استپ Is User Teams Have Role)

این استپ بررسی می‌کند که **حداقل یکی از تیم‌هایی که کاربر عضو آن‌هاست** یک نقش امنیتی (Security Role) مشخص را دارد یا نه.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** به گروه **MvcTeam Security** بروید و **Is User Teams Have Role** را انتخاب کنید.

## پارامترهای ورودی

* **User (اجباری)** : کاربر موردنظر (Lookup به کاربر).
* **Security Role (اجباری)** : نقش امنیتی موردنظر (Lookup به نقش).

## پارامتر خروجی

* **Is User's Teams Have Role** : اگر حداقل یکی از تیم‌های کاربر آن نقش را داشته باشد `True` و در غیر این صورت `False` است.

## نحوه‌ی کار

* فقط نقش‌هایی حساب می‌شوند که به **تیم‌های کاربر** داده شده‌اند. نقشی که مستقیماً به خود کاربر داده شده شمرده نمی‌شود؛ برای آن از [Is User Has Role](is-user-has-role.md) استفاده کنید.
* نقش بر اساس «نقش اصلی» (Root Role) مقایسه می‌شود، پس کپی همان نقش در واحدهای سازمانی مختلف هم یکی حساب می‌شود.
* بررسی با دسترسی **سیستمی** انجام می‌شود.

## نکته‌ها

* اگر می‌خواهید بدانید کاربر «به هر شکلی» نقش را دارد (مستقیم یا از راه تیم)، هر دو استپ [Is User Has Role](is-user-has-role.md) و این استپ را اجرا کنید و نتیجه‌ها را با «یا» در یک شرط ترکیب کنید.
* اگر User یا Security Role خالی باشد، استپ با خطا متوقف می‌شود.
* برای بررسی عضویت در یک تیم مشخص از [Is User Member Of Team](is-user-member-of-team.md) استفاده کنید.
