# اتصال دو متن به هم در Dynamics CRM (استپ Join)

این استپ دو متن را به هم وصل می‌کند و در صورت نیاز یک جداکننده بین آن‌ها می‌گذارد.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Join** را انتخاب کنید.

## پارامترهای ورودی

* **String 1 (اجباری)** : متن اول.
* **String 2 (اجباری)** : متن دوم.
* **Joiner (اختیاری)** : متنی که بین دو متن قرار می‌گیرد. اگر خالی باشد، دو متن بدون جداکننده به هم می‌چسبند.

## پارامتر خروجی

* **Joined String** : متن متصل‌شده.

## مثال

| String 1 | String 2 | Joiner | Joined String |
|---|---|---|---|
| `a` | `b` | `-` | `a-b` |
| `a` | `b` | خالی | `ab` |

## نکته‌ها

* این استپ فقط دو متن را وصل می‌کند. برای وصل کردن چند متن، چند استپ Join را پشت‌سرهم بگذارید.
