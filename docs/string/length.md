# محاسبه‌ی طول متن در Dynamics CRM (استپ Length)

این استپ تعداد نویسه‌های یک متن را برمی‌گرداند.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Length** را انتخاب کنید.

## پارامترهای ورودی

* **String To Measure (اجباری)** : متنی که طول آن خواسته شده.

## پارامتر خروجی

* **String Length** : تعداد نویسه‌ها. برای متن خالی `0` است.

## مثال

| String To Measure | String Length |
|---|---|
| `hello` | `5` |
| خالی | `0` |

## نکته‌ها

* فاصله‌ها هم شمرده می‌شوند. برای شمردن کلمه‌ها از [Word Count](word-count.md) استفاده کنید.
