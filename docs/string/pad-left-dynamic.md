# پُر کردن ابتدای متن تا طول نهایی در Dynamics CRM (استپ Pad Left Dynamic)

این استپ ابتدای یک متن را با Pad Character پُر می‌کند تا متن به **طول نهایی** مشخص برسد؛ مثلاً برای ساخت کد با صفرِ ابتدایی.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Pad Left Dynamic** را انتخاب کنید.

## پارامترهای ورودی

* **String To Pad (اجباری)** : متنی که باید پُر شود.
* **Pad Character (اجباری)** : نویسه‌ای که برای پُر کردن استفاده می‌شود. **نباید خالی باشد.**
* **Length (اجباری)** : طول نهایی مورد نظر.

## پارامتر خروجی

* **Padded String** : متن نهایی.

## مثال

| String To Pad | Pad Character | Length | Padded String |
|---|---|---|---|
| `7` | `0` | `3` | `007` |
| `12345` | `0` | `3` | `12345` |
| `7` | `ab` | `4` | `abab7` |

## نکته‌ها

* اگر متن از قبل به طول نهایی برسد یا از آن بلندتر باشد، بدون تغییر برمی‌گردد.
* اگر Pad Character بیش از یک نویسه باشد، هر بار کل آن اضافه می‌شود؛ پس طول نتیجه ممکن است از Length بیشتر شود (مثال سوم).
* **هشدار: اگر Pad Character خالی باشد و متن کوتاه‌تر از Length باشد، استپ هیچ‌وقت تمام نمی‌شود** و Workflow گیر می‌کند. مطمئن شوید Pad Character همیشه مقدار دارد.
* برای اضافه کردن به انتها از [Pad Right Dynamic](pad-right-dynamic.md) استفاده کنید. اگر می‌خواهید Pad Character را به تعداد مشخص تکرار کنید، از [Pad Left](pad-left.md) استفاده کنید.
