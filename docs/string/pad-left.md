# افزودن نویسه به ابتدای متن در Dynamics CRM (استپ Pad Left)

این استپ یک نویسه (یا متن) را به تعداد مشخص در **ابتدای** متن تکرار می‌کند.

> **مراقب باشید:** پارامتر **Length** در این استپ «طول نهایی» نیست؛ **تعداد دفعاتی** است که Pad Character اضافه می‌شود. اگر می‌خواهید متن تا یک طول نهایی مشخص پُر شود (مثلاً کد ۵ رقمی با صفر در ابتدا)، از [Pad Left Dynamic](pad-left-dynamic.md) استفاده کنید.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Pad Left** را انتخاب کنید.

## پارامترهای ورودی

* **String To Pad (اجباری)** : متنی که به ابتدای آن اضافه می‌شود.
* **Pad Character (اجباری)** : نویسه یا متنی که اضافه می‌شود.
* **Length (اجباری)** : تعداد دفعاتی که Pad Character به ابتدای متن اضافه می‌شود.

## پارامتر خروجی

* **Padded String** : متن نهایی.

## مثال

| String To Pad | Pad Character | Length | Padded String |
|---|---|---|---|
| `7` | `0` | `3` | `0007` |
| `7` | `ab` | `2` | `abab7` |

## نکته‌ها

* برای اضافه کردن به انتهای متن از [Pad Right](pad-right.md) استفاده کنید.
