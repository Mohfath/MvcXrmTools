# پُر کردن انتهای متن تا طول نهایی در Dynamics CRM (استپ Pad Right Dynamic)

این استپ انتهای یک متن را با Pad Character پُر می‌کند تا متن به **طول نهایی** مشخص برسد.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Pad Right Dynamic** را انتخاب کنید.

## پارامترهای ورودی

* **String To Pad (اجباری)** : متنی که باید پُر شود.
* **Pad Character (اجباری)** : نویسه‌ای که برای پُر کردن استفاده می‌شود. **نباید خالی باشد.**
* **Length (اجباری)** : طول نهایی مورد نظر.

## پارامتر خروجی

* **Padded String** : متن نهایی.

## مثال

| String To Pad | Pad Character | Length | Padded String |
|---|---|---|---|
| `7` | `0` | `3` | `700` |

## نکته‌ها

* اگر متن از قبل به طول نهایی برسد یا از آن بلندتر باشد، بدون تغییر برمی‌گردد.
* اگر Pad Character بیش از یک نویسه باشد، هر بار کل آن اضافه می‌شود؛ پس طول نتیجه ممکن است از Length بیشتر شود.
* **هشدار: اگر Pad Character خالی باشد و متن کوتاه‌تر از Length باشد، استپ هیچ‌وقت تمام نمی‌شود** و Workflow گیر می‌کند. مطمئن شوید Pad Character همیشه مقدار دارد.
* برای اضافه کردن به ابتدا از [Pad Left Dynamic](pad-left-dynamic.md) و برای تکرار Pad Character به تعداد مشخص از [Pad Right](pad-right.md) استفاده کنید.
