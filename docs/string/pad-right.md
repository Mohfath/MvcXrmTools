# افزودن نویسه به انتهای متن در Dynamics CRM (استپ Pad Right)

این استپ یک نویسه (یا متن) را به تعداد مشخص در **انتهای** متن تکرار می‌کند.

> **مراقب باشید:** پارامتر **Length** در این استپ «طول نهایی» نیست؛ **تعداد دفعاتی** است که Pad Character اضافه می‌شود. اگر می‌خواهید متن تا یک طول نهایی مشخص پُر شود، از [Pad Right Dynamic](pad-right-dynamic.md) استفاده کنید.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Pad Right** را انتخاب کنید.

## پارامترهای ورودی

* **String To Pad (اجباری)** : متنی که به انتهای آن اضافه می‌شود.
* **Pad Character (اجباری)** : نویسه یا متنی که اضافه می‌شود.
* **Length (اجباری)** : تعداد دفعاتی که Pad Character به انتهای متن اضافه می‌شود.

## پارامتر خروجی

* **Padded String** : متن نهایی.

## مثال

| String To Pad | Pad Character | Length | Padded String |
|---|---|---|---|
| `7` | `0` | `3` | `7000` |

## نکته‌ها

* برای اضافه کردن به ابتدای متن از [Pad Left](pad-left.md) استفاده کنید.
