# ساخت متن تصادفی در Dynamics CRM (استپ Random)

این استپ یک متن تصادفی با طول مشخص می‌سازد. می‌توانید تعیین کنید از چه نوع نویسه‌هایی استفاده شود، یا فهرست نویسه‌های مجاز را خودتان بدهید.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Random** را انتخاب کنید.

## پارامترهای ورودی

* **Length (اجباری)** : طول متن. باید بزرگ‌تر از `0` باشد.
* **Include Upper Case Letters (پیش‌فرض: True)** : حروف بزرگ انگلیسی (`A-Z`).
* **Include Lower Case Letters (پیش‌فرض: True)** : حروف کوچک انگلیسی (`a-z`).
* **Include Numbers (پیش‌فرض: True)** : رقم‌ها (`0-9`).
* **Include Special Characters (پیش‌فرض: True)** : نویسه‌های خاص: ``!"#$%&'()*+,./:;<>?@[\]^_{|}~``. (نویسه‌های `-` و `=` و `` ` `` جزو آن‌ها نیستند.)
* **Allowed Characters (اختیاری)** : فهرست نویسه‌های مجاز. اگر پر شود، **فقط** از همین نویسه‌ها استفاده می‌شود و گزینه‌های بالا نادیده گرفته می‌شوند.

## پارامتر خروجی

* **Random String** : متن تصادفی.

## مثال

| تنظیم | نتیجه |
|---|---|
| Length = `6`، فقط Include Numbers | یک متن شش‌رقمی مثل رمز یک‌بارمصرف |
| Length = `8`، Allowed Characters = `XYZ` | متنی هشت‌نویسه‌ای فقط از `X` و `Y` و `Z` |

## نکته‌ها

* اگر Length کمتر از `1` باشد، استپ با خطای `Length must be greater than 0` متوقف می‌شود.
* اگر هیچ گروهی انتخاب نشود و Allowed Characters هم خالی باشد، استپ با خطا متوقف می‌شود.
* حروف فارسی جزو نویسه‌های پیش‌فرض نیستند؛ برای استفاده از آن‌ها آن‌ها را در Allowed Characters بنویسید.
* این استپ برای مصارف امنیتی (رمز عبور، توکن) مناسب نیست. دو اجرای تقریباً هم‌زمان ممکن است متن یکسان بدهند.
