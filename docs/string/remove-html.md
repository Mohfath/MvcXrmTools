# حذف تگ‌های HTML از متن در Dynamics CRM (استپ Remove Html)

این استپ تگ‌های HTML را از یک متن حذف می‌کند و فقط متن را نگه می‌دارد. جای شکستن خط (پایان پاراگراف، `<br>`، پایان عنوان و پایان آیتم فهرست) در نتیجه با `<br />` نشان داده می‌شود.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Remove Html** را انتخاب کنید.

## پارامترهای ورودی

* **HTML String (اجباری)** : متن HTML.

## پارامتر خروجی

* **HTML Removed String** : متن بدون تگ.

## مثال

| HTML String | HTML Removed String |
|---|---|
| `<p>Hello <b>World</b></p><p>Two</p>` | `Hello World<br />Two<br />` |
| `<ul><li>One</li><li>Two</li></ul>` | `One<br />Two<br />` |
| `Line1<br>Line2` | `Line1<br />Line2` |
| `<div>a &amp; b</div>` | `a &amp; b` |

## نکته‌ها

* تگ‌های شکستن خط (`</p>`، `<br>`، `</h1>` تا `</h3>`، `</li>`) به `<br />` تبدیل می‌شوند، نه به خط جدید. اگر نتیجه را در ایمیل HTML می‌گذارید همین درست است.
* نویسه‌های کدگذاری‌شده مثل `&amp;` و `&nbsp;` رمزگشایی نمی‌شوند؛ برای این کار نتیجه را به [Decode Html](decode-html.md) بدهید.
* فاصله‌های پشت‌سرهم به یک فاصله تبدیل می‌شوند و فاصله‌ی دو طرفِ تگ‌های باقی‌مانده حذف می‌شود.
