# وارونه کردن متن در Dynamics CRM (استپ Reverse)

این استپ ترتیب نویسه‌های یک متن را برعکس می‌کند.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Reverse** را انتخاب کنید.

## پارامترهای ورودی

* **String To Reverse (اجباری)** : متنی که وارونه می‌شود.

## پارامتر خروجی

* **Reversed String** : متن وارونه.

## مثال

| String To Reverse | Reversed String |
|---|---|
| `abc` | `cba` |

## نکته‌ها

* ترتیب نویسه‌ها به‌صورت منطقی در حافظه برعکس می‌شود. برای متن فارسی، ترتیب حروف عوض می‌شود (`سلام` ← `مالس`)؛ نحوه‌ی نمایش راست‌به‌چپ آن در صفحه ممکن است متفاوت به نظر برسد.
