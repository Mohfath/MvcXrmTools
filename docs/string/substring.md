# جدا کردن بخشی از متن در Dynamics CRM (استپ Substring)

این استپ بخشی از یک متن را از یک موقعیت مشخص و با طول مشخص جدا می‌کند.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Substring** را انتخاب کنید.

## پارامترهای ورودی

* **String To Parse (اجباری)** : متنی که از آن بخشی جدا می‌شود.
* **Start Position (اجباری)** : موقعیت شروع؛ شماره‌گذاری از `0` است (`0` یعنی نویسه‌ی اول). مقدار منفی مثل `0` حساب می‌شود.
* **Length (اختیاری)** : تعداد نویسه‌هایی که جدا می‌شوند. اگر خالی یا `0` باشد، از Start Position تا **انتهای متن** جدا می‌شود.

## پارامتر خروجی

* **Partial String** : بخش جداشده.

## مثال

| String To Parse | Start Position | Length | Partial String |
|---|---|---|---|
| `Hello World` | `0` | `5` | `Hello` |
| `Hello World` | `6` | `0` یا خالی | `World` |
| `Hello World` | `6` | `3` | `Wor` |
| `Hello` | `-2` | `3` | `Hel` |
| `Hello` | `2` | `50` | `llo` |

## نکته‌ها

* اگر Length از **کل طول متن** بیشتر باشد، تا انتهای متن جدا می‌شود (مثال آخر).
* **Start Position بعد از انتهای متن:** اگر Start Position از طول متن بیشتر باشد (مثلاً `10` برای متن `Hello`)، استپ خطا نمی‌دهد و خروجی **Partial String خالی** (بدون مقدار) می‌ماند. اگر لازم است این حالت را تشخیص دهید، طول متن را با [Length](length.md) بگیرید و شرط بگذارید.
* **مراقب باشید:** اگر مجموع **Start Position + Length** از طول متن بیشتر شود در حالی که Length خودش از طول متن کمتر باشد (مثلاً متن `Hello`، شروع `3`، طول `4`)، استپ با خطا متوقف می‌شود. برای اینکه خطا نگیرید، مقدارها را طوری بدهید که Start Position + Length از طول متن بیشتر نشود، یا Length را `0` بگذارید تا تا انتهای متن جدا شود.
