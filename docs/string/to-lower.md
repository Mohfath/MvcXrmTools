# تبدیل متن به حروف کوچک در Dynamics CRM (استپ To Lower)

این استپ همه‌ی حروف یک متن را به حروف کوچک تبدیل می‌کند.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **To Lower** را انتخاب کنید.

## پارامترهای ورودی

* **String To Lower (اجباری)** : متنی که تبدیل می‌شود.

## پارامتر خروجی

* **Lowered String** : متن با حروف کوچک.

## مثال

| String To Lower | Lowered String |
|---|---|
| `HeLLo` | `hello` |

## نکته‌ها

* تبدیل بر اساس تنظیمات زبان (Culture) سرور CRM انجام می‌شود.
* حروف فارسی و عربی حرف بزرگ و کوچک ندارند و تغییر نمی‌کنند.
* عکس این استپ [To Upper](to-upper.md) است.
