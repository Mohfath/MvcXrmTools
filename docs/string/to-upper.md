# تبدیل متن به حروف بزرگ در Dynamics CRM (استپ To Upper)

این استپ همه‌ی حروف یک متن را به حروف بزرگ تبدیل می‌کند.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **To Upper** را انتخاب کنید.

## پارامترهای ورودی

* **String To Upper (اجباری)** : متنی که تبدیل می‌شود.

## پارامتر خروجی

* **Uppered String** : متن با حروف بزرگ.

## مثال

| String To Upper | Uppered String |
|---|---|
| `HeLLo` | `HELLO` |

## نکته‌ها

* تبدیل بر اساس تنظیمات زبان (Culture) سرور CRM انجام می‌شود.
* حروف فارسی و عربی حرف بزرگ و کوچک ندارند و تغییر نمی‌کنند.
* عکس این استپ [To Lower](to-lower.md) است.
