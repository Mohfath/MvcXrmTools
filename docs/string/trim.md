# حذف فاصله‌های ابتدا و انتهای متن در Dynamics CRM (استپ Trim)

این استپ فاصله‌های (space) ابتدا و انتهای یک متن را حذف می‌کند. فاصله‌های وسط متن دست نمی‌خورند.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Trim** را انتخاب کنید.

## پارامترهای ورودی

* **String To Trim (اجباری)** : متنی که تمیز می‌شود.

## پارامتر خروجی

* **Trimmed String** : متن بدون فاصله‌ی ابتدا و انتها.

## مثال

| String To Trim | Trimmed String |
|---|---|
| `  a b  ` | `a b` |

## نکته‌ها

* اگر متن خالی باشد، همان مقدار برمی‌گردد.
* برای حذف همه‌ی فاصله‌ها (حتی وسط متن) از [Replace](replace.md) با `Value To Replace` برابر یک فاصله استفاده کنید.
