# کدگذاری متن برای آدرس اینترنتی (URL) در Dynamics CRM (استپ Url Encode)

این استپ یک متن را طوری کدگذاری می‌کند که بتوان آن را با امنیت به‌عنوان بخشی از آدرس اینترنتی (URL) به کار برد. فاصله و نویسه‌های خاص به شکل `%XX` نوشته می‌شوند و حروف غیرانگلیسی (مثل فارسی) به‌صورت UTF-8 کدگذاری می‌شوند.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Url Encode** را انتخاب کنید.

## پارامترهای ورودی

* **String To Encode (اجباری)** : متنی که کدگذاری می‌شود.

## پارامتر خروجی

* **Encoded String** : متن کدگذاری‌شده.

## مثال

| String To Encode | Encoded String |
|---|---|
| `a b&c=d/é` | `a%20b%26c%3Dd%2F%C3%A9` |

## نکته‌ها

* نویسه‌هایی مثل `/` و `&` و `=` هم کدگذاری می‌شوند؛ پس این استپ را فقط روی **یک بخش** آدرس (مثلاً مقدار یک پارامتر) اجرا کنید، نه روی آدرس کامل.
* عکس این استپ [Url Decode](url-decode.md) است. برای کدگذاری HTML از [Encode Html](encode-html.md) استفاده کنید.
