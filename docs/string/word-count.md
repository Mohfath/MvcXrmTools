# شمارش کلمه‌های متن در Dynamics CRM (استپ Word Count)

این استپ تعداد کلمه‌های یک متن را می‌شمارد. کلمه‌ها با **فاصله (space)** از هم جدا می‌شوند.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** استپ **Word Count** را انتخاب کنید.

## پارامترهای ورودی

* **String To Count (اجباری)** : متنی که کلمه‌های آن شمرده می‌شود.

## پارامتر خروجی

* **Word Count** : تعداد کلمه‌ها.

## مثال

| String To Count | Word Count |
|---|---|
| `the quick brown fox` | `4` |
| `  hi  ` (فاصله‌ی دو طرف) | `1` |

## نکته‌ها

* فاصله‌های ابتدا و انتهای متن نادیده گرفته می‌شوند.
* **فقط فاصله جداکننده حساب می‌شود.** اگر بین دو کلمه چند فاصله‌ی پشت‌سرهم باشد (`a  b` ← `3`)، یا کلمه‌ها با خط جدید جدا شده باشند (`a` و `b` در دو خط ← `1`)، شمارش درست نیست. برای شمارش دقیق، پیش از این استپ فاصله‌های اضافه را حذف کنید.
* متن خالی هم `1` برمی‌گرداند. اگر متن ممکن است خالی باشد، پیش از این استپ آن را با [Length](length.md) بررسی کنید.
