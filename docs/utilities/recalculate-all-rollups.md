# محاسبه‌ی مجدد فیلدهای Rollup یک رکورد در Dynamics CRM (استپ Recalculate All Rollups)

این استپ **همه‌ی فیلدهای Rollup منتشرشده‌ی یک رکورد** را دوباره محاسبه می‌کند، بدون اینکه منتظر Job زمان‌بندی‌شده‌ی CRM بمانید.

برای استفاده از این استپ، در طراحی Workflow از منوی **Add Step** به گروه **MvcTeam Utilities** بروید و **Recalculate All Rollups** را انتخاب کنید.

## پارامترهای ورودی

* **Record Reference (اجباری)** : آدرس داینامیک رکوردی که Rollupهای آن محاسبه می‌شوند (**Record URL (Dynamic)**).

این استپ پارامتر خروجی ندارد.

## نحوه‌ی کار

1. نوع رکورد از روی آدرس مشخص می‌شود.
2. همه‌ی فیلدهای Rollup **منتشرشده** (Published) آن نوع رکورد پیدا می‌شوند. فیلد Rollupی که هنوز منتشر نشده باشد نادیده گرفته می‌شود.
3. برای هر فیلد، محاسبه‌ی مجدد اجرا می‌شود. در فیلدهای پولی (Money) نسخه‌ی «ارز پایه» (Base) جدا محاسبه نمی‌شود چون CRM آن را همراه فیلد اصلی محاسبه می‌کند.
4. اگر محاسبه‌ی یک فیلد با خطا روبه‌رو شود، استپ با پیام `Could not recalculate rollup field '…'` متوقف می‌شود و نام فیلد را می‌گوید.

## نکته‌ها

* محاسبه با دسترسی **سیستمی** انجام می‌شود؛ پس به دسترسی کاربر اجراکننده‌ی Workflow بستگی ندارد.
* اگر Record Reference خالی یا نامعتبر باشد، استپ با خطای واضح متوقف می‌شود.
* کاربرد رایج: وقتی رکورد فرزندی ایجاد یا تغییر می‌کند و می‌خواهید مجموع (Sum) و تعداد (Count) در رکورد والد **همان لحظه** به‌روز شود.
* این استپ فقط یک رکورد را محاسبه می‌کند؛ برای رکوردهای زیاد از [Query Run Workflow On Results](query-run-workflow-on-results.md) استفاده کنید.
